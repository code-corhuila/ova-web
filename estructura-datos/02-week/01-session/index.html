Arrays y tipos de datos

El array es la estructura de datos más básica y una de las más usadas. Entender cómo guarda los datos en memoria y cuáles son sus fortalezas y límites es la base para todo lo que viene.

1. Tipos de datos

Antes de agrupar datos hay que conocer sus tipos:

  • Primitivos: guardan un valor directo. En Java: int, double, char, boolean.
  • De referencia: guardan la dirección de un objeto en memoria. Ejemplos: String, arreglos y objetos.

Nota

Un array es un objeto (tipo de referencia) que agrupa muchos valores del mismo tipo bajo un solo nombre.

2. ¿Qué es un array?

Un array almacena sus elementos en posiciones de memoria contiguas, numeradas con un índice que empieza en 0.

índice:   0    1    2    3    4
        +----+----+----+----+----+
valor:  | 10 | 23 |  7 | 42 | 15 |
        +----+----+----+----+----+

Como las posiciones son contiguas, el computador calcula la dirección exacta de cualquier elemento con una fórmula simple. Por eso el acceso por índice es inmediato.

OperaciónCostoPor qué
Acceder por índice a[i]O(1)Cálculo directo de la posición
Recorrer todosO(n)Visita cada elemento una vez
Insertar/eliminar en medioO(n)Hay que desplazar los demás

3. Fortalezas y límites

  • ✅ Acceso instantáneo por índice.
  • ✅ Memoria compacta y predecible.
  • ⚠️ Tamaño fijo: se define al crearlo y no crece solo.
  • ⚠️ Insertar o borrar en el medio obliga a mover elementos.

Cuidado

Acceder a un índice fuera de rango (por ejemplo a[5] en un array de 5 elementos) lanza ArrayIndexOutOfBoundsException.

4. Arrays en Java

int[] numeros = new int[5];      // 5 posiciones (0..4)
numeros[0] = 10;
numeros[1] = 23;
// también: int[] n = {10, 23, 7, 42, 15};
int[] n = {10, 23, 7, 42, 15};
for (int i = 0; i < n.length; i++) {
    System.out.println("Posición " + i + ": " + n[i]);
}
int objetivo = 42, pos = -1;
for (int i = 0; i < n.length; i++) {
    if (n[i] == objetivo) { pos = i; break; }
}
System.out.println(pos == -1 ? "No está" : "En índice " + pos);

Tip

Cuando necesites un tamaño que crezca dinámicamente, más adelante usarás listas (Semana 3) o ArrayList.
