Recorridos básicos en árboles

Un árbol no tiene un único orden natural como una lista. Para procesar la información que guarda, necesitamos recorrerlo: visitar todos sus nodos siguiendo una regla clara. En esta sesión dominarás los cuatro recorridos fundamentales y aprenderás cuándo usar cada uno.

1. ¿Qué es un recorrido?

Un recorrido (o traversal) es el proceso de visitar cada nodo del árbol exactamente una vez, siguiendo un orden definido. "Visitar" significa hacer algo con el nodo: imprimirlo, sumarlo, compararlo, etc.

Recorrido: forma sistemática de visitar todos los nodos de un árbol una sola vez. La diferencia entre un recorrido y otro está en cuándo se visita el nodo actual respecto a sus hijos.

Los recorridos se agrupan en dos familias:

  • En profundidad (DFS): bajan por una rama hasta el final antes de retroceder. Aquí están preorden, inorden y postorden.
  • En amplitud (BFS): visitan el árbol nivel por nivel. Es el recorrido por niveles.

Idea clave

Los tres recorridos en profundidad se distinguen solo por el momento en que se procesa la raíz: antes (pre), en medio (in) o después (post) de sus subárboles.

2. Los cuatro recorridos

Preorden

Se visita primero la raíz, luego el subárbol izquierdo y por último el derecho.

Raíz → Izq → Der

Inorden

Primero el subárbol izquierdo, después la raíz y al final el derecho.

Izq → Raíz → Der

Postorden

Primero ambos subárboles (izq y der) y al final la raíz.

Izq → Der → Raíz

Por niveles

Se visitan los nodos nivel por nivel, de izquierda a derecha (usa una cola).

Nivel 0 → 1 → 2 …

Observa

Aunque el árbol es siempre el mismo, cada recorrido produce una secuencia distinta. El inorden de un árbol binario de búsqueda (ABB) devuelve los datos ordenados de menor a mayor.

Trabajemos sobre el mismo árbol del visualizador:

            A
          /   \
         B     C
        / \     \
       D   E     F
      /

4.1. Preorden (Raíz → Izq → Der)

Visitamos la raíz apenas llegamos a ella y luego bajamos por la izquierda:

A → B → D → G → E → C → F

4.2. Inorden (Izq → Raíz → Der)

Bajamos del todo a la izquierda, visitamos, y volvemos:

G → D → B → E → A → C → F

4.3. Postorden (Izq → Der → Raíz)

La raíz siempre se visita al final de cada subárbol:

G → D → E → B → F → C → A

4.4. Por niveles (BFS)

Nivel por nivel, de izquierda a derecha:

A → B → C → D → E → F → G

5. Implementación en Java

Partimos de una clase Nodo con un dato y dos hijos:

// Recursivo: visita la raíz ANTES que los hijos
void preorden(Nodo n) {
    if (n == null) return;
    visitar(n);              // 1. raíz
    preorden(n.izquierdo);   // 2. izquierda
    preorden(n.derecho);     // 3. derecha
}
// Recursivo: la raíz se visita EN MEDIO
void inorden(Nodo n) {
    if (n == null) return;
    inorden(n.izquierdo);    // 1. izquierda
    visitar(n);              // 2. raíz
    inorden(n.derecho);      // 3. derecha
}
// Recursivo: la raíz se visita AL FINAL
void postorden(Nodo n) {
    if (n == null) return;
    postorden(n.izquierdo);  // 1. izquierda
    postorden(n.derecho);    // 2. derecha
    visitar(n);              // 3. raíz
}
// Iterativo con una COLA (BFS)
void porNiveles(Nodo raiz) {
    if (raiz == null) return;
    Queue<Nodo> cola = new LinkedList<>();
    cola.add(raiz);
    while (!cola.isEmpty()) {
        Nodo n = cola.poll();
        visitar(n);
        if (n.izquierdo != null) cola.add(n.izquierdo);
        if (n.derecho != null)   cola.add(n.derecho);
    }
}

Cuidado con el caso base

Olvidar if (n == null) return; provoca un NullPointerException al llegar a las hojas. Es el error más común al programar recorridos recursivos.

6. ¿Para qué sirve cada uno?

🧮

Inorden

Recorrer un ABB en orden ascendente; imprimir datos ordenados.

📄

Preorden

Copiar o serializar un árbol; mostrar su estructura jerárquica completa.

🗑️

Postorden

Liberar/eliminar nodos desde las hojas hacia la raíz sin perder referencias.

🌐

Por niveles

Camino más corto en árboles; recorrer organigramas o rutas de red.
