Simulación con colas

Modela una fila de atención con una cola y, como reto, implementa una cola circular. Actividad opcional de refuerzo.

1

Usar una cola (enqueue/dequeue/front) para simular una fila.

2

Respetar el orden de llegada (FIFO).

3

(Reto) Implementar una cola circular sobre un arreglo.

1. Enunciado

  1. Implementa (o usa Queue) una cola.
  2. Simula una fila de atención: llegan clientes (enqueue) y se atienden (dequeue) en orden.
  3. Muestra el estado de la fila tras cada operación.
  4. Reto opcional (+): implementa una cola circular sobre un arreglo de tamaño fijo.

2. Requisitos

  • Uso explícito de enqueue/dequeue.
  • Salida que evidencie el orden FIFO.
  • Manejo del caso cola vacía.

3. Cómo entregar

Entrega por GitHub. Repositorio: edatos-s07-colas.

edatos-s07-colas/
  README.md   -> descripcion + resultados
  src/         -> codigo (cola y, opcional, cola circular)
  1. Crea el repo público con ese nombre.
  2. Sube el código y el README.
  3. Comparte el enlace por el canal indicado.
