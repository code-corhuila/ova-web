Colas (Queue)

Si la pila atiende al último que llega, la cola atiende al primero —como en la fila del banco. Es la estructura del orden de llegada, y está detrás de impresoras, servidores y algoritmos como el recorrido por niveles. Aquí la definimos como TAD, resolvemos el desperdicio de espacio con la cola circular y vemos sus variantes.

1. Definición y principio FIFO

Nota

Cola (queue). Estructura lineal en la que los elementos se insertan por un extremo (final) y se extraen por el otro (frente). Cumple la política FIFO (First In, First Out): el primero en entrar es el primero en salir.

Nota

Es la fila del banco: quien llega primero es atendido primero; los nuevos se forman al final.

3. Implementación en Java

Queue<Integer> cola = new LinkedList<>();
cola.add(3);      // enqueue
cola.add(7);
System.out.println(cola.peek()); // 3 (frente)
System.out.println(cola.poll()); // 3 (dequeue)
System.out.println(cola.isEmpty()); // false
class Cola {
    int[] datos = new int[100];
    int frente = 0, fin = 0;
    void enqueue(int x) { datos[fin++] = x; }
    int dequeue() { return datos[frente++]; }
    boolean isEmpty() { return frente == fin; }
}

Cuidado

En la cola con arreglo simple, frente y fin solo avanzan: el espacio liberado al inicio se desperdicia y la cola "se llena" aunque haya huecos. La cola circular lo resuelve.

4. Cola circular (con módulo)

En una cola circular, los índices "dan la vuelta" al llegar al final del arreglo usando el operador módulo %, reaprovechando las posiciones liberadas por dequeue.

class ColaCircular {
    int[] datos; int frente = 0, fin = 0, tam = 0;
    ColaCircular(int cap) { datos = new int[cap]; }
    boolean isFull()  { return tam == datos.length; }
    boolean isEmpty() { return tam == 0; }
    void enqueue(int x) {
        if (isFull()) throw new IllegalStateException("cola llena");
        datos[fin] = x;
        fin = (fin + 1) % datos.length;   // da la vuelta
        tam++;
    }
    int dequeue() {
        if (isEmpty()) throw new IllegalStateException("cola vacía");
        int x = datos[frente];
        frente = (frente + 1) % datos.length;
        tam--;
        return x;
    }
}

Nota

El contador tam distingue cola llena de cola vacía (en ambas frente == fin). Es la forma más clara de evitar esa ambigüedad.

5. Variantes

VarianteIdea
Cola simpleFIFO por un frente y un final
Cola circularReutiliza el arreglo con módulo
Cola de prioridadSale primero el de mayor prioridad, no el más antiguo
Deque (doble)Inserta/quita por ambos extremos

6. Aplicaciones

  • Colas de impresión y de tareas.
  • Atención de solicitudes en servidores (orden de llegada).
  • Buffers de datos (streaming, teclado).
  • Recorrido por niveles (BFS) en árboles y grafos (Semana 9).

Tip

El recorrido por niveles usa una cola: por eso los nodos salen en el orden exacto en que se descubren.

7. Errores comunes

  • Usar cola simple con arreglo y creer que "se llenó" cuando solo se desperdició espacio (usa circular).
  • En la circular, no distinguir llena de vacía (ambas con frente == fin) → usa un contador tam.
  • Confundir el extremo de inserción con el de extracción.
  • Elegir una cola cuando el problema pide LIFO (eso es una pila).
