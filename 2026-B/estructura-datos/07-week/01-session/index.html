Colas (Queue)

Si la pila atiende al último que llega, la cola atiende al primero —como en la fila del banco. Es la estructura de la equidad y del orden de llegada, y está detrás de impresoras, servidores y muchos algoritmos.

1. ¿Qué es una cola?

Una cola (queue) es una estructura lineal donde los elementos se agregan por un extremo (final) y se quitan por el otro (frente). Sigue la regla FIFO: First In, First Out — el primero en entrar es el primero en salir.

Nota

Es la fila del banco: quien llega primero es atendido primero; los nuevos se forman al final.

3. Implementación en Java

Queue<Integer> cola = new LinkedList<>();
cola.add(3);      // enqueue
cola.add(7);
System.out.println(cola.peek()); // 3 (frente)
System.out.println(cola.poll()); // 3 (dequeue)
System.out.println(cola.isEmpty()); // false
class Cola {
    int[] datos = new int[100];
    int frente = 0, fin = 0;
    void enqueue(int x) { datos[fin++] = x; }
    int dequeue() { return datos[frente++]; }
    boolean isEmpty() { return frente == fin; }
}

Cuidado

En una cola con arreglo simple, frente y fin solo avanzan: el espacio del inicio se "desperdicia". La cola circular resuelve esto reutilizando las posiciones.

4. Cola circular

En una cola circular, cuando fin llega al final del arreglo, "da la vuelta" al inicio (con el operador módulo %), aprovechando los espacios liberados por dequeue.

[ _ | _ | 5 | 8 | 2 ]   fin da la vuelta -> escribe en las posiciones libres del inicio

5. ¿Para qué se usan?

  • Colas de impresión y de tareas.
  • Atención de solicitudes en servidores (orden de llegada).
  • Buffers de datos (streaming, teclado).
  • Recorrido por niveles (BFS) en árboles y grafos.

Tip

¿Recuerdas el recorrido por niveles de la Semana 9? Usa una cola: por eso los nodos salen justo en el orden en que se descubren.
