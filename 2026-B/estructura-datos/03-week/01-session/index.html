Listas enlazadas simples

Cuando no sabemos cuántos datos tendremos, el tamaño fijo del array estorba. La lista enlazada crece y se encoge dinámicamente enlazando nodos dispersos en memoria. A cambio de perder el acceso directo por índice, gana flexibilidad para insertar y eliminar.

1. Definición y anatomía del nodo

Nota

Lista enlazada simple. Secuencia de nodos donde cada nodo almacena un dato y una referencia (enlace) al siguiente nodo. La lista se accede desde un puntero inicial, la cabeza (head); el último nodo enlaza a null.

 head
  |
  v
+----+----+   +----+----+   +----+------+
| 10 |  *-+-->| 23 |  *-+-->| 7  | null |
+----+----+   +----+----+   +----+------+
 dato enlace   dato enlace   dato  fin

Nota

A diferencia del array, los nodos no están en memoria contigua: cada uno "sabe" dónde está el siguiente gracias a su referencia. No hay fórmula de dirección → no hay acceso directo por índice.

4. Operaciones y el orden de los enlaces

Cuidado

En las listas, el orden en que reasignas los enlaces es crítico. Si mueves head antes de enlazar el nodo nuevo, pierdes el resto de la lista (queda inalcanzable y la recoge el recolector de basura).

Insertar al inicio: primero el nuevo nodo apunta al actual head; después head pasa a ser el nuevo.

nuevo.siguiente = head;   // 1) el nuevo enlaza al antiguo primero
head = nuevo;             // 2) recién ahora movemos head

Eliminar un nodo: el nodo anterior salta al siguiente del eliminado.

antes:  A -> B -> C
elimina B:  A.siguiente = B.siguiente  (A -> C)
después: A -> C     (B queda sin referencias)

5. Implementación en Java

class Nodo {
    int dato;
    Nodo siguiente;
    Nodo(int dato) { this.dato = dato; this.siguiente = null; }
}
class Lista {
    Nodo head;
    void insertarInicio(int dato) {
        Nodo nuevo = new Nodo(dato);
        nuevo.siguiente = head;   // 1) enlaza al antiguo primero
        head = nuevo;             // 2) el nuevo pasa a ser la cabeza
    }
}
void insertarFinal(int dato) {
    Nodo nuevo = new Nodo(dato);
    if (head == null) { head = nuevo; return; }   // lista vacía
    Nodo actual = head;
    while (actual.siguiente != null) actual = actual.siguiente;
    actual.siguiente = nuevo;
}
void imprimir() {
    Nodo actual = head;
    while (actual != null) {          // verifica != null ANTES de leer
        System.out.print(actual.dato + " -> ");
        actual = actual.siguiente;
    }
    System.out.println("null");
}
void eliminar(int dato) {
    if (head == null) return;
    if (head.dato == dato) { head = head.siguiente; return; }
    Nodo actual = head;
    while (actual.siguiente != null && actual.siguiente.dato != dato)
        actual = actual.siguiente;
    if (actual.siguiente != null) actual.siguiente = actual.siguiente.siguiente;
}

6. Simple vs. doblemente enlazada

En una lista doblemente enlazada cada nodo guarda también un enlace al anterior. Facilita recorrer en ambos sentidos y eliminar un nodo dado en O(1), a costa de más memoria por nodo.

7. Errores comunes

  • Mover head antes de enlazar el nodo nuevo → se pierde la lista.
  • Leer actual.dato sin comprobar actual != null → NullPointerException.
  • Olvidar el caso lista vacía (head == null) en insertar/eliminar.
  • Al eliminar, no manejar el caso de que el nodo buscado sea la cabeza.

Tip

Insertar al inicio es O(1) en una lista; en un array habría que desplazar todo (O(n)). Esa flexibilidad para insertar/eliminar es la ventaja clave de las listas.
