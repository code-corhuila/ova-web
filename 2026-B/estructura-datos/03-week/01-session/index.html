Listas enlazadas simples

Cuando no sabemos cuántos datos tendremos, el array se queda corto por su tamaño fijo. La lista enlazada resuelve esto: crece y se encoge dinámicamente enlazando nodos en memoria.

1. La idea: nodos enlazados

Una lista enlazada simple es una secuencia de nodos. Cada nodo guarda un dato y una referencia al siguiente nodo. El último apunta a null.

 head
  |
  v
+----+----+   +----+----+   +----+------+
| 10 |  *-+-->| 23 |  *-+-->| 7  | null |
+----+----+   +----+----+   +----+------+

Nota

A diferencia del array, los nodos no están en memoria contigua: cada uno "sabe" dónde está el siguiente gracias a su referencia.

2. Lista enlazada vs. array

CaracterísticaArrayLista enlazada
TamañoFijoDinámico
Acceso por índiceO(1)O(n) (hay que recorrer)
Insertar al inicioO(n)O(1)
MemoriaContiguaDispersa (nodos + referencias)

3. Operaciones básicas

  • Recorrer: partir de head e ir saltando por siguiente hasta null.
  • Insertar al inicio: crear el nodo y apuntarlo a head; luego head pasa a ser el nuevo nodo.
  • Eliminar: "saltar" el nodo, haciendo que el anterior apunte al siguiente del eliminado.

Cuidado

Al recorrer, verifica siempre actual != null antes de leer actual.dato, o tendrás un NullPointerException.

4. Implementación en Java

class Nodo {
    int dato;
    Nodo siguiente;
    Nodo(int dato) { this.dato = dato; this.siguiente = null; }
}
class Lista {
    Nodo head;
    void insertarInicio(int dato) {
        Nodo nuevo = new Nodo(dato);
        nuevo.siguiente = head;   // apunta al antiguo primero
        head = nuevo;             // el nuevo pasa a ser la cabeza
    }
}
void imprimir() {
    Nodo actual = head;
    while (actual != null) {
        System.out.print(actual.dato + " -> ");
        actual = actual.siguiente;
    }
    System.out.println("null");
}

Tip

Insertar al inicio de una lista es O(1); en un array habría que desplazar todo (O(n)). Esa es la ventaja clave de las listas.
