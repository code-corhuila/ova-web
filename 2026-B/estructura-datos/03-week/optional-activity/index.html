Implementa una lista enlazada

Construye tu propia lista enlazada simple y comprueba en la práctica por qué es dinámica. Actividad opcional para reforzar la sesión.

1

Implementar una lista enlazada simple con nodos.

2

Realizar inserción al inicio y al final, recorrido y conteo.

3

Verificar el comportamiento con un caso de prueba.

1. Enunciado

  1. Define la clase Nodo (dato + referencia al siguiente).
  2. Implementa la clase Lista con: insertarInicio, insertarFinal, imprimir y contar.
  3. Prueba con 5 elementos e imprime la lista después de cada operación.
  4. Agrega el caso borde: lista vacía.

2. Requisitos

  • Clases Nodo y Lista separadas.
  • Salida que muestre la lista tras cada operación.
  • Manejo del caso lista vacía.

3. Cómo entregar

Entrega por GitHub. Repositorio: edatos-s03-listas.

edatos-s03-listas/
  README.md   -> como ejecutar + resultados
  src/         -> Nodo.java, Lista.java
  1. Crea el repo público con ese nombre.
  2. Sube el código y el README.
  3. Comparte el enlace por el canal indicado.
