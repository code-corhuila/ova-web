Pilas (Stack)

La pila es una estructura tan simple como poderosa. Sigue una única regla —el último en entrar es el primero en salir— y con ella se resuelven desde el botón "deshacer" hasta la ejecución de tus propios programas.

1. ¿Qué es una pila?

Una pila (stack) es una estructura lineal donde los elementos se agregan y se quitan por un solo extremo, llamado tope (top). Funciona con la regla LIFO: Last In, First Out — el último en entrar es el primero en salir.

Nota

Piensa en una pila de platos: solo puedes poner o quitar el de arriba. Nunca sacas uno del medio.

2. Operaciones básicas

OperaciónQué haceCosto
push(x)Agrega x en el topeO(1)
pop()Quita y devuelve el elemento del topeO(1)
peek()Mira el tope sin quitarloO(1)
isEmpty()Indica si la pila está vacíaO(1)

Todas son O(1): no importa cuántos elementos haya, operar en el tope es inmediato.

push(3)      push(7)      pop() -> 7
 | 3 |        | 7 |        | 3 |
 +---+        | 3 |        +---+
              +---+

3. Implementación en Java

Puedes usar la clase Stack o Deque de Java, o construirla tú mismo:

Deque<Integer> pila = new ArrayDeque<>();
pila.push(3);
pila.push(7);
System.out.println(pila.peek()); // 7
System.out.println(pila.pop());  // 7
System.out.println(pila.isEmpty()); // false
class Pila {
    private int[] datos = new int[100];
    private int tope = -1;
    void push(int x) { datos[++tope] = x; }
    int pop() { return datos[tope--]; }
    int peek() { return datos[tope]; }
    boolean isEmpty() { return tope == -1; }
}

Cuidado

Al hacer pop() o peek() en una pila vacía obtendrás un error. Verifica siempre isEmpty() antes.

4. ¿Para qué se usan?

  • Deshacer/rehacer (undo/redo) en editores.
  • Historial del navegador (botón "atrás").
  • Llamadas a funciones: la JVM usa una pila de llamadas (call stack).
  • Evaluar expresiones y verificar paréntesis balanceados.

5. Problema clásico: paréntesis balanceados

Para saber si (a+[b*c]) está bien balanceado, recorres el texto: cada símbolo de apertura se hace push; en cada cierre haces pop y verificas que corresponda.

boolean balanceado(String s) {
    Deque<Character> p = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(' || c == '[') p.push(c);
        else if (c == ')') { if (p.isEmpty() || p.pop() != '(') return false; }
        else if (c == ']') { if (p.isEmpty() || p.pop() != '[') return false; }
    }
    return p.isEmpty();
}

Tip

Si al terminar la pila NO está vacía, quedaron aperturas sin cerrar → no está balanceado.
