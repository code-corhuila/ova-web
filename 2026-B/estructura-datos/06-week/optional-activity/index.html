Aplicaciones de pilas

Pon a trabajar la pila en dos problemas clásicos: invertir texto y validar paréntesis. Actividad opcional para afianzar la sesión.

1

Usar una pila (push/pop/peek) para resolver problemas.

2

Invertir una cadena con una pila.

3

Verificar paréntesis balanceados con varios tipos de símbolo.

1. Enunciado

  1. Implementa (o usa Deque) una pila.
  2. Invierte una cadena de texto usando la pila.
  3. Verifica paréntesis balanceados para (), [] y {}.
  4. Prueba con casos correctos e incorrectos.

2. Requisitos

  • Uso explícito de push/pop.
  • Al menos 3 casos de prueba para el balanceo.
  • Manejo del caso pila vacía.

3. Cómo entregar

Entrega por GitHub. Repositorio: edatos-s06-pilas.

edatos-s06-pilas/
  README.md   -> casos de prueba y resultados
  src/         -> codigo
  1. Crea el repo público con ese nombre.
  2. Sube el código y el README.
  3. Comparte el enlace por el canal indicado.
