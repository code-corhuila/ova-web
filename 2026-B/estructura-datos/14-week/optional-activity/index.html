Analiza la complejidad (Big-O)

Entrena el ojo para la eficiencia: determina la complejidad de varios fragmentos y compáralos. Actividad opcional de refuerzo.

1

Determinar la complejidad Big-O de fragmentos de código.

2

Justificar cada resultado.

3

Comparar el crecimiento de O(n) vs O(n²).

1. Enunciado

  1. Para 4 fragmentos de código (un bucle, dos bucles anidados, una búsqueda binaria y un acceso por índice), indica su Big-O y justifícalo.
  2. Calcula el número de operaciones de O(n) vs O(n²) para n = 10, 100 y 1000.
  3. Explica en una frase por qué evitar O(n²) cuando la entrada es grande.

2. Requisitos

  • Justificación por fragmento.
  • Tabla comparativa O(n) vs O(n²).

3. Cómo entregar

Entrega por GitHub. Repositorio: edatos-s14-bigo.

edatos-s14-bigo/
  README.md   -> Big-O de cada fragmento + tabla comparativa
  src/         -> (opcional) fragmentos analizados
  1. Crea el repo público con ese nombre.
  2. Sube el análisis y el README.
  3. Comparte el enlace por el canal indicado.
