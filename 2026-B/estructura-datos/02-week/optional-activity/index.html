Operaciones sobre arrays

Practica el manejo de arrays implementando las operaciones más comunes y razonando su costo. Actividad opcional para afianzar lo visto en la sesión.

1

Recorrer un array e implementar operaciones básicas.

2

Calcular suma, promedio, máximo y mínimo.

3

Explicar por qué cada recorrido es O(n).

1. Enunciado

  1. Crea un array con 8 números enteros.
  2. Implementa métodos para: suma total, promedio, valor máximo y valor mínimo.
  3. Imprime los cuatro resultados.
  4. Explica en el README por qué cada recorrido es O(n).

2. Requisitos

  • Un método por operación (código modular).
  • Salida verificable de los 4 resultados.
  • Breve explicación de la complejidad.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase (enlace dado por el docente) y clónalo.
  2. Coloca tu entrega en la carpeta `02-week/` correspondiente a esta semana.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 02" · git push (abre un Pull Request si el docente lo pide).
  4. Verifica que tienes tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER); sin él, tus entregas no se detectan.
