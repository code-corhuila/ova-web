Arrays y tipos de datos

El array es la estructura de datos más elemental y una de las más usadas. Entender cómo guarda los datos en memoria contigua explica por qué su acceso es inmediato pero su tamaño es fijo. Esa comprensión es la base de todo lo que viene.

1. Tipos de datos: primitivos y de referencia

CategoríaQué guardanEjemplos (Java)
PrimitivosEl valor directoint, double, char, boolean, long
De referenciaLa dirección de un objeto en memoriaString, arreglos, objetos

Nota

Un array es un objeto (tipo de referencia): la variable guarda la dirección del bloque de memoria donde viven los elementos, no los elementos en sí.

2. Definición y modelo de memoria

Nota

Array (arreglo). Colección de elementos del mismo tipo almacenados en posiciones de memoria contiguas, accesibles por un índice entero que comienza en 0.

índice:   0    1    2    3    4
        +----+----+----+----+----+
valor:  | 10 | 23 |  7 | 42 | 15 |
        +----+----+----+----+----+
dir:    100  104  108  112  116     (int = 4 bytes)

Como las celdas son contiguas y del mismo tamaño, la dirección de a[i] se calcula con una fórmula directa:

direccion(a[i]) = direccion_base + i * tamaño_del_tipo

Nota

Por esa fórmula, acceder a cualquier elemento cuesta lo mismo: O(1). No importa si es a[0] o a[999999].

3. Costo de las operaciones

OperaciónCostoPor qué
Acceder por índice a[i]O(1)Cálculo directo de la dirección
Recorrer todosO(n)Visita cada elemento una vez
Buscar (desordenado)O(n)Puede estar en cualquier posición
Insertar/eliminar al final (con espacio)O(1)No desplaza nada
Insertar/eliminar en medioO(n)Hay que desplazar los elementos siguientes
Insertar 99 en la posición 1 (hay que correr todo a la derecha):
antes:  | 10 | 23 |  7 | 42 |
        insertar 99 en [1]  ->  desplazar 23,7,42
después:| 10 | 99 | 23 |  7 | 42 |

4. Fortalezas y límites

  • ✅ Acceso instantáneo por índice (O(1)).
  • ✅ Memoria compacta, contigua y predecible (buena para la caché).
  • ⚠️ Tamaño fijo: se define al crear el array y no crece solo.
  • ⚠️ Insertar o borrar en el medio obliga a desplazar elementos (O(n)).

Cuidado

Acceder a un índice fuera de rango (p. ej. a[5] en un array de 5 elementos, índices 0..4) lanza ArrayIndexOutOfBoundsException. El índice válido va de 0 a length - 1.

5. Arrays en Java

int[] numeros = new int[5];      // 5 posiciones (0..4), inicializadas en 0
numeros[0] = 10;
numeros[1] = 23;
// literal: int[] n = {10, 23, 7, 42, 15};
int[] n = {10, 23, 7, 42, 15};
for (int i = 0; i < n.length; i++) {
    System.out.println("Posición " + i + ": " + n[i]);
}
// for-each cuando no necesitas el índice:
for (int v : n) System.out.println(v);
int objetivo = 42, pos = -1;
for (int i = 0; i < n.length; i++) {
    if (n[i] == objetivo) { pos = i; break; }
}
System.out.println(pos == -1 ? "No está" : "En índice " + pos);

6. Arrays multidimensionales

Un array 2D (matriz) es un array de arrays; se accede con dos índices m[fila][col]:

int[][] m = new int[3][4];   // 3 filas, 4 columnas
m[0][0] = 1;  m[2][3] = 9;

7. Errores comunes

  • Usar length - 1 como tamaño o iterar i <= n.length (desborda el rango).
  • Suponer que el array "crece" al asignar más allá de su tamaño (no crece; lanza excepción).
  • Confundir array.length (atributo, sin paréntesis) con String.length() (método).
  • Insertar en medio en un bucle sin contar el costo O(n) de cada desplazamiento.

Tip

Cuando necesites un tamaño que crezca dinámicamente, usarás listas (Semana 3) o ArrayList, que gestionan el redimensionamiento por ti.
