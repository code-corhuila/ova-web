Cierre y portafolio

Cierra el semestre dejando tu proyecto pulido y una breve reflexión de lo aprendido. Actividad opcional para tu portafolio.

1

Incorporar la retroalimentación al proyecto final.

2

Pulir el repositorio y su documentación.

3

Reflexionar sobre lo aprendido en el curso.

1. Enunciado

  1. Aplica la retroalimentación recibida a tu proyecto final (correcciones, casos borde, README).
  2. Deja el repositorio pulido: commits claros, instrucciones de ejecución.
  3. Escribe una reflexión (media página): qué estructura te resultó más útil y por qué; qué mejorarías.
  4. Agrega el proyecto a tu portafolio de GitHub (fíjalo/destácalo).

2. Requisitos

  • Ajustes de la retroalimentación aplicados.
  • README final claro.
  • Reflexión personal incluida.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase (enlace dado por el docente) y clónalo.
  2. Coloca tu entrega en la carpeta `16-week/` correspondiente a esta semana.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 16" · git push (abre un Pull Request si el docente lo pide).
  4. Verifica que tienes tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER); sin él, tus entregas no se detectan.
