Gestión de datos con estructuras

Llevemos todo a la práctica: construir un pequeño sistema que dé de alta, liste, busque y elimine datos. Aquí verás cómo la estructura elegida moldea cada operación de un CRUD real.

1

Aplicar una estructura de datos a operaciones de gestión (CRUD).

2

Elegir la estructura según las operaciones más frecuentes del sistema.

3

Implementar altas, listado, búsqueda y baja sobre una colección.

1. Gestionar datos = CRUD

Casi todo sistema hace cuatro cosas con sus datos, el CRUD:

  • Create (crear / dar de alta)
  • Read (leer / listar / buscar)
  • Update (actualizar)
  • Delete (eliminar / dar de baja)

Nota

La estructura que elijas define qué tan eficiente es cada letra del CRUD. Un mismo sistema puede sentirse rápido o lento solo por esa decisión.

2. Ejemplo: gestión de estudiantes

Queremos registrar estudiantes y consultarlos. Analicemos qué operación domina:

OperaciónFrecuenciaEstructura que ayuda
Registrar (alta)AltaLista (agrega fácil)
Listar todosMediaLista o array
Buscar por códigoMuy altaÁrbol de búsqueda / mapa
EliminarBajaLista (elimina sin desplazar)

Si buscar es lo más frecuente, conviene una estructura de búsqueda; si predominan altas/bajas, una lista.

3. Implementación con una lista

class Estudiante {
    int codigo; String nombre;
    Estudiante(int c, String n) { codigo = c; nombre = n; }
}
List<Estudiante> lista = new LinkedList<>();
lista.add(new Estudiante(101, "Ana"));   // Create
lista.add(new Estudiante(102, "Luis"));
for (Estudiante e : lista)                // Read (listar)
    System.out.println(e.codigo + " - " + e.nombre);

Estudiante encontrado = null;             // Read (buscar)
for (Estudiante e : lista)
    if (e.codigo == 102) { encontrado = e; break; }
if (encontrado != null) encontrado.nombre = "Luis A."; // Update
lista.removeIf(e -> e.codigo == 101);                  // Delete

Cuidado

Buscar en una lista es O(n): recorre uno por uno. Si el sistema busca millones de veces, ese O(n) se nota — ahí conviene una estructura de búsqueda (tema de la Semana 14).

4. Del problema a la estructura

Pasos para decidir en un sistema de gestión:

  1. Lista las operaciones del sistema.
  2. Marca cuál se ejecuta con más frecuencia.
  3. Elige la estructura que haga esa operación más barata.
  4. Verifica que las demás operaciones sigan siendo aceptables.
