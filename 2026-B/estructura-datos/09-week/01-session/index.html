Recorridos de árboles

Un árbol solo es útil si podemos visitar sus nodos en un orden con sentido. Los recorridos definen cuatro maneras sistemáticas de hacerlo —preorden, inorden, postorden y por niveles— cada una idónea para una tarea distinta, desde imprimir un ABB ordenado hasta evaluar una expresión.

1

Distinguir recorridos en profundidad (DFS) y en anchura (BFS).

2

Implementar preorden, inorden y postorden de forma recursiva.

3

Implementar el recorrido por niveles con una cola.

4

Elegir el recorrido adecuado según la tarea.

1. Dos grandes familias

Nota

Recorrido (traversal). Proceso de visitar todos los nodos de un árbol exactamente una vez, en un orden definido. En profundidad (DFS) se baja por una rama antes de retroceder; en anchura (BFS) se visita nivel por nivel.

FamiliaEstrategiaSe apoya en
DFS (profundidad)Baja por una rama hasta el fondo, luego retrocedeRecursión / pila
BFS (anchura)Visita nivel por nivel, de izquierda a derechaCola

2. Los tres recorridos en profundidad

Se diferencian en cuándo se visita la raíz respecto a sus subárboles:

RecorridoOrdenUso típico
Preordenraíz → izq → derCopiar/serializar el árbol
Inordenizq → raíz → derEn un ABB, da los datos ordenados
Postordenizq → der → raízLiberar/borrar; evaluar expresiones

Sobre este árbol:

        8
      /   \
     3     10
    / \      \
   1   6      14
RecorridoResultado
Preorden8, 3, 1, 6, 10, 14
Inorden1, 3, 6, 8, 10, 14 (¡ordenado!)
Postorden1, 6, 3, 14, 10, 8

Nota

El inorden de un ABB siempre produce los elementos en orden ascendente. Es la forma natural de listar un ABB ordenado.

3. Implementación recursiva (DFS)

La recursión sigue la estructura del árbol: resolver el nodo = resolver sus subárboles.

void preorden(Nodo n) {
    if (n == null) return;        // caso base
    System.out.print(n.dato + " ");  // 1) raíz
    preorden(n.izquierdo);           // 2) izq
    preorden(n.derecho);             // 3) der
}
void inorden(Nodo n) {
    if (n == null) return;
    inorden(n.izquierdo);            // 1) izq
    System.out.print(n.dato + " ");  // 2) raíz
    inorden(n.derecho);              // 3) der
}
void postorden(Nodo n) {
    if (n == null) return;
    postorden(n.izquierdo);          // 1) izq
    postorden(n.derecho);            // 2) der
    System.out.print(n.dato + " ");  // 3) raíz
}

Nota

El único cambio entre los tres es el momento en que se procesa la raíz (antes, entre o después de las llamadas a los hijos). El caso base n == null detiene la recursión.

4. Recorrido por niveles (BFS)

Usa una cola: se encola la raíz; en cada paso se desencola un nodo, se procesa y se encolan sus hijos. Así los nodos salen nivel por nivel.

void porNiveles(Nodo raiz) {
    if (raiz == null) return;
    Queue<Nodo> cola = new LinkedList<>();
    cola.add(raiz);
    while (!cola.isEmpty()) {
        Nodo n = cola.poll();
        System.out.print(n.dato + " ");
        if (n.izquierdo != null) cola.add(n.izquierdo);
        if (n.derecho != null)   cola.add(n.derecho);
    }
}

Resultado en el árbol anterior: 8, 3, 10, 1, 6, 14 (nivel por nivel).

Nivel 0:  8
Nivel 1:  3      10
Nivel 2:  1  6       14

5. Costo

Nota

Todo recorrido visita cada nodo una vez → O(n) en tiempo. DFS recursivo usa la pila de llamadas (memoria O(altura)); BFS usa una cola (memoria O(ancho del nivel más grande)).

6. ¿Cuál elegir?

Necesitas…Usa
Listar un ABB ordenadoInorden
Copiar/serializar la estructuraPreorden
Borrar/evaluar de abajo hacia arribaPostorden
Procesar por cercanía a la raíz (nivel)Por niveles (BFS)

7. Errores comunes

  • Olvidar el caso base n == null → recursión infinita / NullPointerException.
  • Colocar la impresión de la raíz en el lugar equivocado (cambia el tipo de recorrido).
  • Usar una pila creyendo que hará BFS: el recorrido por niveles necesita una cola.
  • Esperar que el inorden ordene un árbol que no es ABB.
