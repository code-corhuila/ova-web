Implementa y compara los recorridos de un árbol

Lleva a código lo aprendido en la sesión: implementa los cuatro recorridos, pruébalos sobre un árbol dado y argumenta cuándo conviene cada uno. Es una actividad opcional pensada para afianzar la competencia; no se entrega en Moodle.

⏱

Duración estimada: 2–3 horas.

👤

Modalidad: individual o parejas.

💻

Lenguaje: Java (o el de tu preferencia).

🔗

Entrega: repositorio en GitHub.

1. Objetivos de aprendizaje

  • Implementar los recorridos preorden, inorden y postorden de forma recursiva.
  • Implementar el recorrido por niveles (BFS) usando una cola.
  • Verificar los resultados sobre un árbol de prueba y casos borde (árbol vacío, un solo nodo).
  • Argumentar, con criterio técnico, qué recorrido conviene para cada necesidad.

2. Enunciado

Dado el siguiente árbol binario:

            A
          /   \
         B     C
        / \     \
       D   E     F
      /
     G

Tareas

  1. Define una clase Nodo con un dato y dos hijos (izquierdo/derecho) y construye el árbol anterior en tu programa.
  2. Implementa cuatro métodos: preorden, inorden, postorden y porNiveles.
  3. Imprime las cuatro secuencias y verifica que coinciden con las de la sesión.
  4. Agrega dos casos borde: árbol vacío y árbol de un solo nodo.
  5. Escribe un breve análisis (media página) respondiendo: ¿para qué tarea usarías cada recorrido y por qué?

Reto opcional (+)

Implementa además una versión iterativa del inorden usando una pila explícita, y compárala con la recursiva.

3. Requisitos técnicos

📦

Estructura

Código organizado; una clase por responsabilidad.

🧪

Pruebas

Salida verificable de las 4 secuencias + casos borde.

📝

Documentación

README con instrucciones de ejecución y el análisis.

🔁

Historial

Commits con mensajes claros y progresivos.

4. Cómo entregar

La entrega es por GitHub (no por Moodle), con nombre y estructura estandarizados para que sea fácil de revisar.

Nombre del repositorio

Usa el patrón <sigla>-s<NN>-<tema> en minúsculas y con guiones. Para esta actividad:

edatos-s09-recorridos

Estructura del repositorio (refleja la rúbrica)

edatos-s09-recorridos/
├── README.md   → objetivo · cómo ejecutar · resultados (4 secuencias) · casos borde · análisis
├── src/        → código fuente de los recorridos
└── tests/      → pruebas y casos borde (árbol vacío / un nodo)

Cada carpeta responde a un criterio de la rúbrica: src/ → recorridos DFS/BFS; tests/ → pruebas y casos borde; README.md → análisis y calidad del repositorio.

Pasos

  1. Crea el repositorio público con el nombre indicado.
  2. Organiza el código según la estructura anterior.
  3. Redacta el README.md cubriendo, en secciones, los criterios de la rúbrica.
  4. Comparte el enlace del repositorio por el canal indicado por el docente.
  5. Verifica tu avance con esta lista:
  • Clase Nodo y construcción del árbol.
  • Preorden, inorden y postorden (recursivos).
  • Recorrido por niveles (BFS con cola).
  • Casos borde: árbol vacío y de un nodo.
  • Análisis de cuándo usar cada recorrido.
  • README con instrucciones y resultados.

Nota

Actividad formativa y opcional (sin nota en Moodle); su objetivo es consolidar la competencia antes del parcial del Corte 2. La guía unificada para entregar todas las actividades opcionales, válida para todas las materias, estará en el Manual de Entrega de Actividades Opcionales (genérico, próximamente).
