Recorridos de un árbol binario

Implementa los cuatro recorridos de un árbol binario y comprueba con ejemplos cómo cambia el orden de visita. Refuerza la recursión y el uso de una cola para BFS. Actividad opcional de refuerzo.

1

Implementar preorden, inorden y postorden de forma recursiva.

2

Implementar el recorrido por niveles con una cola.

3

Verificar que el inorden de un ABB sale ordenado.

1. Enunciado

  1. Construye un ABB insertando al menos 7 valores (elígelos tú).
  2. Implementa los cuatro recorridos: preorden, inorden, postorden (recursivos) y por niveles (con cola).
  3. Imprime el resultado de cada recorrido.
  4. Comprueba que el inorden sale ordenado y explica en el README por qué.

2. Requisitos

  • Los cuatro recorridos implementados y funcionando.
  • Caso base null correcto en los recorridos recursivos.
  • BFS usando una cola (Queue/LinkedList).
  • Evidencia de que el inorden queda ordenado.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase (enlace dado por el docente) y clónalo.
  2. Coloca tu entrega en la carpeta `09-week/` correspondiente a esta semana.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 09" · git push (abre un Pull Request si el docente lo pide).
  4. Verifica que tienes tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER); sin él, tus entregas no se detectan.
