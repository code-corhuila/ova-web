Guía de repaso del Corte 1

Consolida el Corte 1 resolviendo un set de ejercicios de repaso antes del parcial. Actividad opcional de preparación.

1

Repasar fundamentos, arrays, listas y programación estructurada.

2

Resolver ejercicios integradores del corte.

3

Autoevaluar la preparación para el parcial.

1. Enunciado

Resuelve y documenta los siguientes ejercicios:

  1. Explica la diferencia entre tipo primitivo y de referencia con un ejemplo.
  2. Dado int[] a = {4, 9, 1, 7}, escribe el código para el promedio.
  3. Implementa contarPares(int[] a) que devuelva cuántos pares hay.
  4. Dibuja (ASCII) una lista enlazada de 3 nodos e indica a qué apunta el último.
  5. Explica por qué insertar al inicio de una lista es más eficiente que en un array.

2. Requisitos

  • Respuestas justificadas (no solo el resultado).
  • Código compilable para los ejercicios de programación.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase (enlace dado por el docente) y clónalo.
  2. Coloca tu entrega en la carpeta `05-week/` correspondiente a esta semana.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 05" · git push (abre un Pull Request si el docente lo pide).
  4. Verifica que tienes tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER); sin él, tus entregas no se detectan.
