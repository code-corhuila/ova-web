2. Repaso exprés

  • TAD: define el qué (operaciones), no el cómo (implementación).
  • Array: memoria contigua, acceso O(1), tamaño fijo.
  • Lista enlazada: nodos con referencia al siguiente, dinámica, acceso O(n), inserción al inicio O(1).
  • Programación estructurada: secuencia, decisión, repetición + funciones con una sola responsabilidad.

Tip

Si dudas entre array o lista, pregúntate: ¿necesito acceso rápido por índice (array) o inserciones/eliminaciones frecuentes y tamaño variable (lista)?

3. Ejercicios tipo parcial

  1. Explica con tus palabras la diferencia entre un tipo primitivo y uno de referencia.
  2. Dado int[] a = {4, 9, 1, 7}, escribe el código para hallar el promedio.
  3. Dibuja una lista enlazada con 3 nodos e indica a qué apunta el último.
  4. Escribe una función contarPares(int[] a) que devuelva cuántos números pares hay.
  5. ¿Por qué insertar al inicio de una lista es más eficiente que en un array?

Cuidado

En el parcial se evalúa el razonamiento, no solo el resultado. Explica tus pasos y justifica la estructura que eliges.

4. Preparación para el parcial

  • Modalidad: individual, teórico-práctico.
  • Temas: semanas 1 a 4.
  • Trae lápiz y papel para trazar arrays y listas.
