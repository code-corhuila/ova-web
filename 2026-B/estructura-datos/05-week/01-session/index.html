2. Síntesis conceptual

  • TAD: especifica el qué (operaciones y comportamiento); la implementación define el cómo. Un TAD admite varias implementaciones.
  • Array: memoria contigua, acceso por índice O(1), tamaño fijo; insertar en medio es O(n).
  • Lista enlazada: nodos con referencia al siguiente, dinámica, acceso O(n), insertar al inicio O(1); cuidado con el orden de los enlaces.
  • Programación estructurada: secuencia, decisión, repetición (Böhm-Jacopini) + funciones con una responsabilidad (alta cohesión, bajo acoplamiento).

4. Criterio de elección

Tip

Pregúntate por la operación dominante. ¿Muchos accesos por índice y tamaño conocido? → array. ¿Muchas inserciones/eliminaciones y tamaño variable? → lista enlazada.

5. Ejercicios tipo parcial (con razonamiento)

1) Diferencia entre tipo primitivo y de referencia. Razonamiento: el primitivo guarda el valor (int x = 5); el de referencia guarda la dirección de un objeto (int[] a, String s).

2) Dado int[] a = {4, 9, 1, 7}, promedio.

int s = 0; for (int x : a) s += x;
double prom = (double) s / a.length;   // 21/4 = 5.25

3) Lista de 3 nodos: dibuja los enlaces e indica a qué apunta el último. Respuesta: el último apunta a null.

4) contarPares(int[] a):

static int contarPares(int[] a) {
    int c = 0;
    for (int x : a) if (x % 2 == 0) c++;
    return c;
}

5) ¿Por qué insertar al inicio de una lista es más eficiente que en un array? Razonamiento: en la lista solo se reasignan dos referencias (O(1)); en el array hay que desplazar todos los elementos (O(n)).

Cuidado

En el parcial se evalúa el razonamiento, no solo el resultado. Explica tus pasos y justifica la estructura que eliges.

6. Errores frecuentes a evitar

  • Confundir TAD con implementación.
  • Iterar i <= a.length (desborda) en vez de i < a.length.
  • Mover head antes de enlazar el nodo nuevo (se pierde la lista).
  • Afirmar que un array "crece" solo.
