Proyecto final con estructuras y complejidad

Todo converge aquí. El proyecto final te pide construir una solución real eligiendo estructuras con criterio y justificando su eficiencia con Big-O. Es la evidencia de que dominas el curso, del diseño a la implementación.

1

Integrar varias estructuras de datos en un proyecto funcional.

2

Justificar cada elección con su complejidad (Big-O).

3

Diseñar antes de programar (flujo + estructuras).

4

Documentar y entregar el proyecto por GitHub.

1. Objetivo del proyecto

Desarrollar un programa que resuelva un problema real de gestión, eligiendo las estructuras adecuadas y analizando la complejidad de sus operaciones principales. No se evalúa solo que funcione, sino por qué elegiste cada estructura y con qué costo.

Nota

El proyecto es la síntesis del semestre: fundamentos (C1) + estructuras lineales y árboles (C2) + selección y eficiencia (C3).

2. Requisitos mínimos (checklist)

  • Usar al menos tres estructuras distintas (p. ej. lista, pila/cola y árbol o mapa).
  • Implementar un CRUD completo sobre los datos.
  • Incluir una búsqueda y justificar su Big-O.
  • Justificar cada estructura por su operación dominante y su costo.
  • Entregar un README con problema, estructuras, justificación y análisis de complejidad.

3. Método: diseño antes de código

  1. Define el problema y lista las operaciones del sistema.
  2. Marca la operación dominante de cada parte.
  3. Asigna a cada una la estructura que la hace más barata.
  4. Anota la Big-O de las operaciones clave.
  5. Recién entonces, programa.
Problema -> Operaciones -> (operacion dominante) -> Estructura -> Big-O -> Codigo

4. Temas sugeridos

  • Gestor de biblioteca (préstamos, reservas, catálogo).
  • Sistema de turnos de una clínica.
  • Agenda de contactos con búsqueda rápida.
  • Inventario de una tienda.
  • Reproductor de música (playlist + historial + undo).

Tip

Empieza por el diseño (Semana 13): dibuja el flujo y asigna estructuras antes de programar. Ahorra tiempo y sube tu nota en el criterio de justificación.
