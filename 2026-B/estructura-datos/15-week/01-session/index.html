Proyecto final con estructuras y complejidad

Todo converge aquí. El proyecto final te pide construir una solución real eligiendo estructuras con criterio y justificando su eficiencia con Big-O. Es la evidencia de que dominas el curso.

1

Integrar varias estructuras de datos en un proyecto funcional.

2

Justificar cada elección con su complejidad (Big-O).

3

Documentar y entregar el proyecto por GitHub.

1. Objetivo del proyecto

Desarrollar un programa que resuelva un problema real de gestión, eligiendo las estructuras adecuadas y analizando la complejidad de sus operaciones principales. No se evalúa solo que funcione, sino por qué elegiste cada estructura.

Nota

El proyecto es la síntesis del semestre: fundamentos (C1) + estructuras lineales y árboles (C2) + selección y eficiencia (C3).

2. Requisitos mínimos

  • Usar al menos tres estructuras distintas (p. ej. lista, pila/cola y árbol o mapa).
  • Implementar un CRUD completo sobre los datos.
  • Incluir una búsqueda y justificar su Big-O.
  • Entregar un README con: problema, estructuras elegidas, justificación y análisis de complejidad.

3. Temas sugeridos

  • Gestor de biblioteca (préstamos, reservas, catálogo).
  • Sistema de turnos de una clínica.
  • Agenda de contactos con búsqueda rápida.
  • Inventario de una tienda.
  • Reproductor de música (playlist + historial).

  docs/       -> diagrama del diseno (estructuras y flujo)
  • Elegí un tema y definí las operaciones del sistema.
  • Seleccioné 3+ estructuras y justifiqué cada una.
  • Implementé el CRUD y la búsqueda.
  • Analicé la Big-O de las operaciones clave.
  • Redacté el README y subí el repositorio a GitHub.

Tip

Empieza por el diseño (Semana 13): dibuja el flujo y asigna estructuras antes de programar. Ahorra tiempo y mejora tu nota en el criterio de justificación.
