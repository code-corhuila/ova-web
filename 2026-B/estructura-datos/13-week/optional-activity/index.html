Diseña un sistema con varias estructuras

Integra lo aprendido diseñando un sistema real que combine varias estructuras. Actividad opcional de refuerzo previa al proyecto.

1

Descomponer un sistema en operaciones.

2

Asignar la estructura adecuada a cada operación.

3

Documentar el diseño antes de programar.

1. Enunciado

Diseña (no hace falta implementarlo completo) un sistema de biblioteca:

  1. Lista las operaciones (préstamos, cola de reservas, historial por usuario, deshacer).
  2. Asigna a cada una la estructura adecuada y justifícalo.
  3. Dibuja el flujo (ASCII o imagen) mostrando cómo se conectan.
  4. Implementa 2 de las operaciones en código.

2. Requisitos

  • Tabla operación → estructura → justificación.
  • Diagrama de flujo del diseño.
  • 2 operaciones implementadas.

3. Cómo entregar

Entrega por GitHub. Repositorio: edatos-s13-diseno.

edatos-s13-diseno/
  README.md   -> tabla + diagrama + justificacion
  src/         -> 2 operaciones implementadas
  1. Crea el repo público con ese nombre.
  2. Sube diseño y código.
  3. Comparte el enlace por el canal indicado.
