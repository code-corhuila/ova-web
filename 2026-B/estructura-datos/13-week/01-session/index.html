Aplicación práctica de estructuras de datos

Es hora de integrar. En esta sesión resolvemos un caso realista combinando varias estructuras, para que veas cómo trabajan juntas en un programa de verdad y no de forma aislada.

1

Integrar varias estructuras en la solución de un problema.

2

Justificar la estructura elegida para cada parte del sistema.

3

Diseñar la solución antes de programar (del problema al modelo).

1. Del ejercicio al sistema

Hasta ahora estudiamos cada estructura por separado. En un programa real conviven varias: una elección para almacenar, otra para procesar, otra para ordenar la atención. Integrarlas bien es la competencia clave del corte.

Nota

Regla práctica: divide el problema en operaciones, y asigna a cada una la estructura que la hace más simple y eficiente.

2. Caso: mesa de ayuda (help desk)

Un sistema de tickets de soporte debe:

  • Registrar tickets que llegan (orden de llegada).
  • Atender en orden de llegada, salvo los urgentes.
  • Consultar el historial de un usuario.
  • Deshacer la última acción del operador.
NecesidadEstructuraPor qué
Atender por llegadaColaFIFO respeta el orden
Tickets urgentes primeroCola de prioridadSale primero el más urgente
Historial por usuarioListaCrece dinámico, se recorre
Deshacer acciónPilaLIFO: la última primero

3. Diseño antes de programar

Ticket ---> [ Cola de entrada ] ---> Operador ---> [ Pila de acciones (undo) ]
                                         |
                                         v
                              [ Lista historial por usuario ]

Diseñar el flujo primero evita reescribir código: sabes qué estructura toca en cada punto.

4. Esqueleto en Java

Queue<Ticket> entrada = new LinkedList<>();          // llegada (FIFO)
Deque<Accion> deshacer = new ArrayDeque<>();         // undo (LIFO)
Map<Integer, List<Ticket>> historial = new HashMap<>(); // por usuario
void registrar(Ticket t) {
    entrada.add(t);
    historial.computeIfAbsent(t.usuario, k -> new LinkedList<>()).add(t);
}
Ticket atender() { return entrada.poll(); }   // el primero en llegar
void hacer(Accion a) { deshacer.push(a); }
Accion undo() { return deshacer.isEmpty() ? null : deshacer.pop(); }

Tip

Fíjate cómo cada método usa la estructura adecuada: poll (cola) para atender, push/pop (pila) para deshacer, List para el historial.
