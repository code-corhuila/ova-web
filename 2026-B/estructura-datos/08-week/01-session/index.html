Árboles binarios simples

Hasta ahora usamos estructuras lineales. Los árboles introducen una organización jerárquica que modela relaciones "padre a hijos" y hace muy eficientes la búsqueda y el orden. Esta sesión define el árbol con precisión, fija la terminología y sienta las bases para los recorridos de la Semana 9.

1. Definiciones

Nota

Árbol. Estructura jerárquica de nodos donde existe un nodo especial (raíz) y cada nodo se conecta con cero o más hijos. Todo nodo tiene exactamente un padre, salvo la raíz que no tiene padre. No hay ciclos.

Nota

Árbol binario. Árbol en el que cada nodo tiene a lo sumo dos hijos, distinguidos como hijo izquierdo y hijo derecho.

4. Tipos de árbol binario

TipoDefinición
Lleno (full)Cada nodo tiene 0 o 2 hijos (nunca 1)
CompletoTodos los niveles llenos salvo quizá el último, cargado a la izquierda
Equilibrado (balanceado)La altura de los subárboles difiere en poco → altura ~ log n
ABB (BST)Para cada nodo: izquierda < nodo < derecha

Nota

En un árbol binario equilibrado con n nodos, la altura es aproximadamente log₂(n). Por eso buscar en un ABB equilibrado cuesta O(log n): en cada paso se descarta la mitad. Si el árbol se degenera (todo hacia un lado), se comporta como una lista: O(n).

5. La propiedad del ABB (árbol binario de búsqueda)

Nota

ABB. Árbol binario donde, para todo nodo, los valores del subárbol izquierdo son menores y los del derecho son mayores. Esta invariante permite buscar descartando la mitad en cada comparación.

        8
      /   \
     3     10      buscar 6: 6<8 -> izq; 6>3 -> der; encontrado
    / \      \
   1   6      14

6. Implementación en Java

class Nodo {
    int dato;
    Nodo izquierdo, derecho;
    Nodo(int dato) { this.dato = dato; }  // hijos = null por defecto
}
Nodo raiz = new Nodo(1);                 // A
raiz.izquierdo = new Nodo(2);            // B
raiz.derecho = new Nodo(3);              // C
raiz.izquierdo.izquierdo = new Nodo(4);  // D
raiz.izquierdo.derecho = new Nodo(5);    // E
Nodo insertar(Nodo r, int x) {
    if (r == null) return new Nodo(x);
    if (x < r.dato) r.izquierdo = insertar(r.izquierdo, x);
    else if (x > r.dato) r.derecho = insertar(r.derecho, x);
    return r;   // duplicados: se ignoran
}

Cuidado

Todo nodo nace con hijos null. Antes de leer nodo.izquierdo.dato verifica que el hijo no sea null, o tendrás un NullPointerException.

7. Aplicaciones

  • Sistemas de archivos: carpetas y subcarpetas.
  • Árboles de búsqueda (ABB): búsquedas e inserciones eficientes.
  • Árboles de expresión: operadores y operandos.
  • Árboles de decisión y motores de reglas.

8. Errores comunes

  • Confundir altura (del árbol) con profundidad (de un nodo).
  • Acceder a un hijo sin comprobar null.
  • Suponer que un ABB siempre es O(log n): si se degenera, es O(n).
  • Insertar en un ABB sin respetar la invariante izquierda < nodo < derecha.

Tip

En la Semana 9 aprenderás a recorrer el árbol (preorden, inorden, postorden y por niveles). El inorden de un ABB devuelve los datos ordenados.
