Árboles binarios simples

Hasta ahora usamos estructuras lineales (arrays, listas, pilas, colas). Los árboles introducen una organización jerárquica que modela relaciones de "padre a hijos" y hace muy eficientes la búsqueda y el orden. Esta sesión sienta las bases para los recorridos de la Semana 9.

1. ¿Qué es un árbol?

Un árbol es una estructura de datos jerárquica formada por nodos. Cada nodo guarda un dato y se conecta con otros nodos "hijos". A diferencia de una lista, un nodo puede tener varios hijos, pero un solo padre (excepto la raíz, que no tiene padre).

Nota

Un árbol binario es un árbol donde cada nodo tiene como máximo dos hijos: el hijo izquierdo y el hijo derecho.

1.1 Terminología esencial

  • Raíz (root): el nodo superior, único sin padre.
  • Nodo hoja (leaf): nodo sin hijos.
  • Hijo / padre: relación directa entre dos nodos conectados.
  • Nivel: distancia en aristas desde la raíz (la raíz está en el nivel 0).
  • Altura: el nivel más profundo del árbol.
  • Profundidad de un nodo: número de aristas desde la raíz hasta ese nodo.

2. Anatomía de un árbol binario

Observa el siguiente árbol binario:

          A          <- raíz (nivel 0)
        /   \
       B     C       <- nivel 1
      / \     \
     D   E     F     <- nivel 2 (D, E, F son hojas)

3. Implementación en Java

Un árbol binario se construye a partir de una clase Nodo que se referencia a sí misma (hijo izquierdo y derecho).

class Nodo {
    int dato;
    Nodo izquierdo;
    Nodo derecho;

    Nodo(int dato) {
        this.dato = dato;
        this.izquierdo = null;
        this.derecho = null;
    }
}
Nodo raiz = new Nodo(1);        // A
raiz.izquierdo = new Nodo(2);   // B
raiz.derecho = new Nodo(3);     // C
raiz.izquierdo.izquierdo = new Nodo(4); // D
raiz.izquierdo.derecho = new Nodo(5);   // E

Cuidado

Todo nodo nuevo nace con sus hijos en null. Antes de acceder a nodo.izquierdo.dato verifica que el hijo no sea null para evitar un NullPointerException.

4. ¿Para qué se usan los árboles?

  • Sistemas de archivos: carpetas y subcarpetas forman un árbol.
  • Árboles de decisión y motores de reglas.
  • Árboles binarios de búsqueda (ABB): búsquedas e inserciones eficientes.
  • Expresiones matemáticas: un árbol representa operadores y operandos.

Tip

En la Semana 9 aprenderás a recorrer este árbol (preorden, inorden, postorden y por niveles) para procesar toda su información en el orden adecuado.
