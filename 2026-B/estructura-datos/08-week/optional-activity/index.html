Construye un árbol binario

Construye tu primer árbol binario en código e identifica sus partes. Base perfecta para los recorridos de la Semana 9. Actividad opcional de refuerzo.

1

Definir la clase Nodo de un árbol binario.

2

Construir un árbol e identificar raíz, hojas y altura.

3

Acceder a nodos concretos del árbol.

1. Enunciado

  1. Dibuja (ASCII) un árbol binario con al menos 7 nodos e identifica raíz, hojas y altura.
  2. Define la clase Nodo (dato + hijo izquierdo/derecho).
  3. Construye ese árbol en Java.
  4. Imprime el dato de la raíz y de sus dos hijos.

2. Requisitos

  • Dibujo del árbol en el README.
  • Construcción correcta con la clase Nodo.
  • Verificación de null antes de acceder a hijos.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase (enlace dado por el docente) y clónalo.
  2. Coloca tu entrega en la carpeta `08-week/` correspondiente a esta semana.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 08" · git push (abre un Pull Request si el docente lo pide).
  4. Verifica que tienes tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER); sin él, tus entregas no se detectan.
