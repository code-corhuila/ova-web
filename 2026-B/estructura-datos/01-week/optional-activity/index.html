Estructuras de datos en aplicaciones reales

Lleva la teoría al mundo real: identifica qué estructuras de datos hacen posible las apps que usas todos los días y argumenta por qué encajan. Es una actividad opcional para afianzar el criterio de selección.

1

Reconocer estructuras de datos detrás de aplicaciones cotidianas.

2

Clasificar estructuras en lineales y no lineales.

3

Justificar por qué una estructura encaja con un problema.

1. Enunciado

Elige tres aplicaciones que uses a diario (por ejemplo: reproductor de música, chat, mapa/GPS, red social, banca).

  1. Para cada app, escoge una función concreta (p. ej. "lista de reproducción", "historial de chat", "ruta más corta").
  2. Propón qué estructura de datos podría estar detrás de esa función.
  3. Clasifícala como lineal o no lineal y explica por qué encaja (2–3 líneas).
  4. Arma una tabla resumen con: app, función, estructura, tipo y justificación.

2. Requisitos

  • Mínimo 3 aplicaciones, cada una con su función y estructura.
  • Uso correcto de los conceptos: TAD, lineal / no lineal.
  • Redacción clara; la justificación es lo más importante.

3. Cómo entregar

La entrega es por GitHub (no por Moodle), con nombre y estructura estandarizados.

Nombre del repositorio: patrón <sigla>-s<NN>-<tema> en minúsculas. Para esta actividad: edatos-s01-estructuras.

Estructura del repositorio (refleja la rúbrica):

edatos-s01-estructuras/
  README.md   -> las 3 apps, la tabla resumen y la justificacion
  docs/        -> (opcional) capturas o diagramas de apoyo

Pasos:

  1. Crea el repositorio público con el nombre indicado.
  2. Redacta el README.md con tu análisis y la tabla resumen.
  3. Comparte el enlace por el canal indicado por el docente.
