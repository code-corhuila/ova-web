Formulación de problemas y búsqueda no informada

Muchísimos problemas —rutas, rompecabezas, planificación— se resuelven igual: como una búsqueda en un espacio de estados. Aprender a formular un problema de esa forma y a recorrer el espacio con BFS, DFS y costo uniforme te da una herramienta que reutilizarás toda tu carrera.

1. Un problema como espacio de estados

Nota

Formular una búsqueda requiere cinco piezas: estado inicial, acciones posibles, modelo de transición (a qué estado lleva cada acción), prueba de meta (¿es este el objetivo?) y costo de cada paso. Con eso, resolver el problema es hallar un camino del estado inicial a uno meta.

Ejemplo: ir de Neiva a Bogotá. Estados = ciudades; acciones = carreteras; costo = kilómetros; meta = Bogotá.

2. El árbol de búsqueda

El algoritmo explora un árbol cuyos nodos son estados. La diferencia entre estrategias está en qué nodo expandir primero (la "frontera").

3. BFS vs. DFS

  • Búsqueda en amplitud (BFS): expande por niveles (usa una cola). Es completa y óptima si el costo es uniforme, pero gasta mucha memoria (O(b^d)).
  • Búsqueda en profundidad (DFS): baja por una rama hasta el fondo (usa una pila). Usa poca memoria (O(b·m)), pero no es óptima y puede perderse en ramas infinitas.
from collections import deque

def bfs(inicio, es_meta, vecinos):
    frontera = deque([inicio])
    padres = {inicio: None}
    while frontera:
        n = frontera.popleft()          # BFS: FIFO (cola)
        if es_meta(n):
            return reconstruir(padres, n)
        for v in vecinos(n):
            if v not in padres:
                padres[v] = n
                frontera.append(v)
    return None                          # sin solución

4. Búsqueda de costo uniforme

Cuando los pasos cuestan distinto, BFS deja de ser óptima. La búsqueda de costo uniforme expande siempre el nodo de menor costo acumulado g(n) (usa una cola de prioridad). Es óptima con costos no negativos y es la base del algoritmo A\* de la próxima semana.

Cuidado

No confundas "menos pasos" con "menor costo". De Neiva a Bogotá, una ruta con menos tramos puede ser más larga en km. BFS minimiza pasos; costo uniforme minimiza costo real.

5. Errores comunes

  • No marcar estados visitados → ciclos infinitos y trabajo repetido.
  • Usar DFS esperando la ruta óptima (no lo garantiza).
  • Aplicar BFS en espacios enormes y quedarse sin memoria.
