Regresión lineal — el modelo más sencillo

Antes de redes neuronales o árboles, existe la regresión lineal: sencilla, interpretable y sorprendentemente poderosa. Entenderla a fondo es entender cómo aprende cualquier modelo — minimizar un error ajustando parámetros.

1. La idea central

Nota

Una recta y = wx + b predice un valor continuo a partir de una entrada. El modelo aprende los valores de w (pendiente) y b (intercepto) que mejor se ajustan a los datos.

Ejemplo: predecir el precio de una casa (y) a partir de su área en m² (x).

2. Error cuadrático medio (MSE)

Para medir qué tan lejos están las predicciones de los valores reales usamos el MSE:

MSE = (1/n) · Σ (yᵢ - ŷᵢ)²
  • yᵢ = valor real · ŷᵢ = predicción
  • Elevamos al cuadrado para penalizar más los errores grandes y evitar cancelaciones.

3. Descenso por gradiente

El algoritmo ajusta w y b iterativamente en la dirección que reduce el MSE:

def entrenar(X, y, lr=0.01, epocas=1000):
    w, b = 0.0, 0.0
    n = len(X)
    for _ in range(epocas):
        y_pred = w * X + b
        dw = (-2/n) * sum(X * (y - y_pred))
        db = (-2/n) * sum(y - y_pred)
        w -= lr * dw   # mover w en sentido contrario al gradiente
        b -= lr * db
    return w, b

Tip

lr (learning rate) controla el tamaño del paso. Demasiado grande = oscilación; demasiado pequeño = convergencia lenta.

4. Interpretar los coeficientes

  • w = 1 500 → por cada m² adicional, el precio sube $1 500.
  • b = 20 000 → precio base estimado de una casa de 0 m² (intercepto, a veces no tiene sentido literal).

5. Errores comunes

  • No escalar las variables (las de rangos grandes dominan el gradiente).
  • Usar regresión lineal en relaciones claramente no lineales.
  • Evaluar solo con MSE y no visualizar los residuales.

Cierre de la sesión

La regresión lineal aprende una recta ajustando w y b para minimizar el MSE mediante descenso por gradiente. Es el modelo base cuya mecánica —función de costo + optimización iterativa— se replica en todos los demás algoritmos de ML. Semana 7: clasificación binaria con regresión logística.
