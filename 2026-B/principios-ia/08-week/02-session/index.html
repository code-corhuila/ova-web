Naive Bayes — probabilidad para clasificación

Naive Bayes aplica el teorema de Bayes asumiendo que todas las variables son independientes entre sí. Esta simplificación 'ingenua' resulta en un modelo rapidísimo, robusto con pocos datos y sorprendentemente efectivo para texto y clasificación de documentos.

1. Teorema de Bayes

Nota

P(C|X) = P(X|C) · P(C) / P(X) — la probabilidad de la clase C dado el ejemplo X se calcula combinando cuán probable es observar X en la clase C con cuán frecuente es esa clase en general.

  • Prior P(C): frecuencia de la clase en los datos de entrenamiento.
  • Likelihood P(X|C): probabilidad de ver las características X dado que es clase C.
  • Posterior P(C|X): lo que queremos — probabilidad de la clase dado el ejemplo.

2. La suposición "naive"

Naive Bayes supone que todas las características son independientes entre sí dado el valor de la clase:

P(x₁,x₂,...,xₙ|C) ≈ P(x₁|C) · P(x₂|C) · ... · P(xₙ|C)

Esto rara vez es cierto en la realidad, pero simplifica enormemente el cálculo y funciona bien en la práctica para texto.

3. Clasificación de spam

from sklearn.naive_bayes import MultinomialNB
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.pipeline import Pipeline

pipe = Pipeline([
    ('vec', CountVectorizer()),        # texto → frecuencias de palabras
    ('nb',  MultinomialNB(alpha=1.0)), # alpha=1: suavizado de Laplace
])
pipe.fit(X_train_text, y_train)
pred = pipe.predict(["ganaste un premio gratis llama ya"])
print(pred)  # ['spam']

Tip

El suavizado de Laplace (alpha=1) evita probabilidades de cero cuando una palabra no aparece en una clase del entrenamiento.

5. Errores comunes

  • No aplicar suavizado → probabilidades cero que anulan todo.
  • Usar Naive Bayes con variables continuas sin la variante Gaussian.
  • Esperar que funcione bien cuando hay interacción fuerte entre variables.
