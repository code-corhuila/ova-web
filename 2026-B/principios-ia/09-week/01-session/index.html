Evaluación de modelos — validación cruzada y matriz de confusión

Saber entrenar un modelo es solo la mitad del trabajo. La otra mitad es medirlo correctamente. Un modelo mal evaluado puede parecer excelente y fallar en producción. Esta sesión da las herramientas para confiar en las métricas.

1

Aplicar validación cruzada k-fold para estimar el desempeño real.

2

Construir e interpretar una matriz de confusión completa.

3

Trazar e interpretar una curva ROC y calcular el AUC.

4

Distinguir error de entrenamiento, validación y prueba.

1. El problema de un solo split

Dividir datos en 80% entrenamiento / 20% prueba depende de qué datos caen en cada parte. Con pocos datos, el resultado puede ser muy variable.

Nota

Validación cruzada k-fold divide los datos en k partes; entrena en k-1 y prueba en la restante, rotando k veces. El desempeño final es el promedio de las k pruebas — más robusto y con estimación de varianza.

from sklearn.model_selection import cross_val_score
import numpy as np

scores = cross_val_score(modelo, X, y, cv=5, scoring='f1')
print(f"F1 promedio: {scores.mean():.3f} ± {scores.std():.3f}")

2. Matriz de confusión detallada

  • VP (Verdaderos Positivos): predijo + y era +.
  • VN (Verdaderos Negativos): predijo - y era -.
  • FP (Falso Positivo / alarma falsa): predijo + pero era -.
  • FN (Falso Negativo / caso perdido): predijo - pero era +.

3. Curva ROC y AUC

from sklearn.metrics import roc_curve, auc
import matplotlib.pyplot as plt

fpr, tpr, _ = roc_curve(y_test, proba)
area = auc(fpr, tpr)
plt.plot(fpr, tpr, label=f"AUC = {area:.2f}")
plt.plot([0,1],[0,1],'--', color='gray')
plt.xlabel("Tasa de Falsos Positivos"); plt.ylabel("Tasa de Verdaderos Positivos")
plt.legend(); plt.show()

Tip

AUC = 0.5 → el modelo no discrimina (igual que azar). AUC = 1.0 → clasificación perfecta. Un buen modelo tiene AUC > 0.75.
