Sesgo-varianza, regularización y selección de modelos

Todo modelo de ML enfrenta el mismo dilema: ser suficientemente complejo para capturar el patrón pero no tanto que memorice el ruido. El framework sesgo-varianza da el vocabulario preciso para diagnosticar y corregir este balance.

Definir sesgo y varianza en el contexto de ML.

Usar curvas de aprendizaje para diagnosticar underfitting y overfitting.

Seleccionar hiperparámetros con búsqueda en cuadrícula (GridSearchCV).

1. El dilema sesgo-varianza

Nota

Sesgo (Bias): error por suposiciones erróneas del modelo — demasiado simple para los datos (underfitting). Varianza: error por sensibilidad al ruido — demasiado complejo (overfitting). El objetivo es minimizar ambos simultáneamente.

2. Curvas de aprendizaje

from sklearn.model_selection import learning_curve
import matplotlib.pyplot as plt
import numpy as np

tam, tr_scores, val_scores = learning_curve(
    modelo, X, y, cv=5, train_sizes=np.linspace(0.1, 1.0, 10)
)
plt.plot(tam, tr_scores.mean(axis=1),  label="Entrenamiento")
plt.plot(tam, val_scores.mean(axis=1), label="Validación")
plt.xlabel("Tamaño del entrenamiento"); plt.legend(); plt.show()

3. Regularización

Agrega un término de penalización al error para controlar la complejidad del modelo:

from sklearn.linear_model import Ridge, Lasso

# Ridge (L2): penaliza el cuadrado de los coeficientes
ridge = Ridge(alpha=1.0)

# Lasso (L1): penaliza el valor absoluto → puede llevar coeficientes a 0 (selección)
lasso = Lasso(alpha=0.1)

Tip

Ridge distribuye la reducción entre todos los coeficientes. Lasso elimina coeficientes irrelevantes — hace selección automática de variables.

4. Búsqueda de hiperparámetros

from sklearn.model_selection import GridSearchCV

param_grid = {'alpha': [0.001, 0.01, 0.1, 1.0, 10.0]}
gs = GridSearchCV(Ridge(), param_grid, cv=5, scoring='neg_mean_squared_error')
gs.fit(X_train, y_train)
print("Mejor alpha:", gs.best_params_)
