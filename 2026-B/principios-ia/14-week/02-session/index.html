Taller presencial — Orange y ML sin código

Orange es una plataforma visual de ML donde los algoritmos se conectan como bloques. Sin escribir una línea de código puedes cargar datos, entrenar modelos, comparar algoritmos y visualizar resultados. Ideal para explorar conceptos y explicarlos a audiencias no técnicas.

1

Instalar y navegar la interfaz de Orange.

2

Construir un flujo completo de clasificación con bloques visuales.

3

Comparar modelos usando el widget Test & Score.

4

Exportar y documentar los resultados del taller.

1. ¿Qué es Orange?

Nota

Orange (orange.biolab.si) es software de código abierto para análisis de datos visual. Cada operación —cargar datos, limpiar, entrenar, evaluar— es un widget que se conecta a otros formando flujos de trabajo sin escribir código.

2. Flujo básico de clasificación

[File] → [Data Table] → [Select Columns]
                               ↓
               [Logistic Regression]  [Random Forest]  [Naive Bayes]
                               ↓              ↓              ↓
                          [Test & Score] ← conectar los tres modelos
                               ↓
                     [Confusion Matrix]  [ROC Analysis]

Pasos en el taller

  1. Widget File → cargar iris.csv o titanic.csv.
  2. Data Table → explorar filas y columnas.
  3. Select Columns → definir variable objetivo (target).
  4. Arrastrar 3 clasificadores al canvas.
  5. Test & Score → conectar los clasificadores; revisar AUC, F1, accuracy.
  6. Confusion Matrix → ver errores por clase.
  7. ROC Analysis → comparar curvas de los modelos.

3. Actividad: dataset personalizado

Actividad del taller:
1. Descargar dataset de Kaggle (heart disease, diabetes, o iris).
2. Cargar en Orange con widget File.
3. Visualizar distribuciones con Distribution y Scatter Plot.
4. Entrenar: árbol de decisión + SVM + kNN.
5. Comparar en Test & Score (CV = 10 folds).
6. Documentar el mejor modelo con captura de pantalla.
7. Interpretar la matriz de confusión del mejor modelo.

Tip

Orange permite exportar el flujo como imagen (.ows) y los resultados como CSV. Documenta tu taller guardando el archivo .ows — puede reproducirse exactamente en otra máquina.

4. Weka — alternativa clásica

Weka (cs.waikato.ac.nz/ml/weka) es el estándar académico clásico: interfaz Java, amplia colección de algoritmos y exportación a código Java. Útil cuando se requiere integración con sistemas Java o comparación con literatura antigua.
