Inferencia difusa — sistema Mamdani

Un sistema de inferencia difusa convierte entradas numéricas en una decisión usando reglas lingüísticas del tipo SI-ENTONCES. El método Mamdani es el más intuitivo y más usado en control industrial y sistemas expertos.

1. Las cuatro etapas del sistema Mamdani

Entradas numéricas
       ↓
[1] FUZZIFICACIÓN   → grados de membresía para cada variable
       ↓
[2] EVALUACIÓN DE   → aplicar reglas SI-ENTONCES con min/max
    REGLAS
       ↓
[3] AGREGACIÓN      → combinar salidas de todas las reglas
       ↓
[4] DEFUZZIFICACIÓN → convertir el conjunto difuso de salida a un número
       ↓
Salida numérica (decisión)

2. Ejemplo: control de propina

Reglas:

  • SI servicio es malo ENTONCES propina es baja.
  • SI servicio es bueno Y comida es buena ENTONCES propina es alta.
  • SI comida es excelente ENTONCES propina es generosa.
import numpy as np

# Universos de discurso
servicio = np.arange(0, 11, 0.1)   # 0-10
propina  = np.arange(0, 26, 0.5)   # 0-25%

# Funciones de membresía (simplificadas)
def trimf(x, a, b, c):
    return np.clip(np.minimum((x-a)/(b-a+1e-9), (c-x)/(c-b+1e-9)), 0, 1)

serv_malo   = trimf(servicio, 0, 0, 5)
serv_bueno  = trimf(servicio, 3, 7, 10)
prop_baja   = trimf(propina, 0, 5, 13)
prop_alta   = trimf(propina, 13, 20, 25)

# Fuzzificación para servicio = 6.5
mu_malo  = float(trimf(np.array([6.5]), 0, 0, 5))
mu_bueno = float(trimf(np.array([6.5]), 3, 7, 10))

# Inferencia (recorte con min)
regla1_salida = np.minimum(mu_malo,  prop_baja)
regla2_salida = np.minimum(mu_bueno, prop_alta)

# Agregación (max)
agregado = np.maximum(regla1_salida, regla2_salida)

# Defuzzificación — centroide
centroide = np.sum(propina * agregado) / (np.sum(agregado) + 1e-9)
print(f"Propina recomendada: {centroide:.1f}%")

3. Defuzzificación: el centroide

Nota

El centroide (center of gravity) calcula el "centro de masa" del conjunto difuso de salida. Es el método más usado porque produce decisiones suaves y continuas.

COG = Σ(x · μ(x)) / Σμ(x)
