Lógica difusa — conjuntos y funciones de membresía

La lógica clásica es binaria: verdadero o falso. Pero el mundo real es impreciso: alguien puede ser 'bastante alto', la temperatura 'un poco fría'. La lógica difusa formaliza ese razonamiento gradual y permite construir sistemas de control e inferencia con lenguaje natural.

1. Del blanco y negro al gradiente

Nota

En lógica difusa, la membresía de un elemento a un conjunto es un valor en [0, 1] — no 0 o 1. "Temperatura alta" puede tener membresía 0.8 a 35°C y 0.3 a 28°C.

Ejemplos cotidianos de imprecisión: "joven", "cerca", "mucho tráfico", "precio justo".

3. Operaciones difusas

OperaciónFórmula
Unión (OR)μ(A∪B) = max(μ_A, μ_B)
Intersección (AND)μ(A∩B) = min(μ_A, μ_B)
Complemento (NOT)μ(Ā) = 1 − μ_A
import numpy as np

def triangular(x, a, b, c):
    # Función de membresía triangular
    return np.maximum(0, np.minimum((x-a)/(b-a), (c-x)/(c-b)))

x = np.linspace(0, 40, 400)
fria     = triangular(x,  0, 10, 20)
templada = triangular(x, 15, 25, 35)
caliente = triangular(x, 30, 40, 50)

4. Aplicaciones reales

  • Control de lavarropas (velocidad de centrifugado según nivel de suciedad).
  • Cámaras automáticas (foco y exposición adaptativos).
  • Control de trenes (frenado suave según distancia a la estación).
  • Sistemas de diagnóstico médico (clasificación de síntomas imprecisos).

Tip

La lógica difusa brilla cuando las reglas son de tipo lingüístico: "si la temperatura es alta Y la humedad es mucha, entonces el riesgo de incendio es muy alto".
