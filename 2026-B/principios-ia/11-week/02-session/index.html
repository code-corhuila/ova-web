Panorama del Deep Learning — CNN, RNN y Transformers

El deep learning es una familia de arquitecturas especializadas. Las CNN dominan imágenes, las RNN el tiempo y el texto secuencial, y los Transformers han revolucionado el lenguaje natural. Conocerlas permite elegir la arquitectura correcta para cada problema.

1. Redes Convolucionales (CNN)

Nota

Una CNN aplica filtros que deslizan sobre la imagen detectando bordes, texturas y formas. Las capas iniciales detectan patrones simples; las profundas combinan para reconocer objetos completos.

Ventajas: compartición de pesos (el mismo filtro en toda la imagen) y invarianza a traslación.

import tensorflow as tf

cnn = tf.keras.Sequential([
    tf.keras.layers.Conv2D(32, (3,3), activation='relu', input_shape=(28,28,1)),
    tf.keras.layers.MaxPooling2D(2,2),
    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(10, activation='softmax'),
])

2. Redes Recurrentes (RNN / LSTM)

Las RNN procesan secuencias manteniendo un estado oculto que pasa información entre pasos:

3. Transformers y Atención

Nota

En lugar de procesar secuencias paso a paso, los Transformers calculan atención entre todas las posiciones simultáneamente. Esto permite paralelización masiva y captura dependencias de largo alcance.

Modelos fundamentales:

  • BERT → comprensión de texto (clasificación, extracción).
  • GPT → generación de texto.
  • ViT → visión por transformers.

4. Transferencia de aprendizaje

base = tf.keras.applications.MobileNetV2(weights='imagenet', include_top=False)
base.trainable = False   # congelar pesos preentrenados

modelo = tf.keras.Sequential([base, tf.keras.layers.GlobalAveragePooling2D(),
                               tf.keras.layers.Dense(10, activation='softmax')])

Tip

No hay que entrenar desde cero. Los modelos preentrenados en ImageNet o texto masivo son reutilizables para nuevas tareas con pocos datos.
