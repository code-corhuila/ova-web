Integración end-to-end — de datos crudos al modelo desplegado

Los proyectos de IA del mundo real no son notebooks aislados. Son pipelines que van de datos crudos a predicciones servidas por una API, con monitoreo, documentación y código reproducible. Esta sesión integra todo el semestre en un flujo completo.

1. El flujo completo

Datos crudos → EDA → Preprocesamiento → Entrenamiento → Evaluación
                                                              ↓
              Monitoreo ← Despliegue ← Empaquetado ← Selección de modelo

Cada etapa produce artefactos: datos limpios, modelos .pkl, métricas, APIs, dashboards.

2. Exponer el modelo como API con FastAPI

from fastapi import FastAPI
from pydantic import BaseModel
import joblib, numpy as np

app   = FastAPI(title="Predictor IA", version="1.0")
model = joblib.load("modelo_titanic.pkl")

class Pasajero(BaseModel):
    pclass: int; age: float; sibsp: int; parch: int; fare: float

@app.post("/predict")
def predict(p: Pasajero):
    X = np.array([[p.pclass, p.age, p.sibsp, p.parch, p.fare]])
    pred  = int(model.predict(X)[0])
    proba = float(model.predict_proba(X)[0, 1])
    return {"sobrevive": bool(pred), "probabilidad": round(proba, 3)}

# Ejecutar: uvicorn main:app --reload
# Documentación automática: http://localhost:8000/docs

Tip

FastAPI genera documentación interactiva (Swagger UI) automáticamente. Puedes probar el endpoint desde el browser en /docs.

4. Monitoreo en producción

Cuidado

Los modelos se degradan con el tiempo. Si la distribución de los datos cambia (data drift) o los patrones del mundo cambian (concept drift), la exactitud cae. Se requiere monitoreo continuo y re-entrenamiento periódico.

Señales de alerta: aumento de tasa de error, distribución de predicciones cambiada, quejas de usuarios.
