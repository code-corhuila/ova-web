Asesoría de proyectos finales — revisión y retroalimentación

La sesión de asesoría convierte los avances individuales en proyectos sólidos. El docente revisa el estado de cada proyecto, identifica bloqueantes técnicos y éticos, y alinea las presentaciones con los criterios de evaluación.

1

Presentar el estado de avance del proyecto (datos, modelo, resultados parciales).

2

Recibir retroalimentación técnica y ética sobre el enfoque elegido.

3

Identificar los ajustes necesarios antes de la presentación final.

4

Conocer los criterios de evaluación de la presentación de la semana 16.

1. Agenda de la sesión de asesoría

Cada grupo dispone de 10-15 minutos para presentar:

  1. Problema elegido — ¿qué se predice/clasifica? ¿por qué es relevante?
  2. Dataset — fuente, tamaño, variables, calidad de los datos.
  3. Modelo actual — algoritmo elegido, métricas preliminares.
  4. Bloqueante principal — ¿qué impide avanzar?

2. Lista de verificación previa a la presentación

Ítem✓
Dataset cargado y explorado (EDA básico)
Variable objetivo definida claramente
Al menos un modelo entrenado con métricas
Conjunto de prueba separado desde el inicio
Al menos una reflexión ética documentada
Repositorio GitHub con README
Slides / demo preparados

3. Criterios de evaluación semana 16

CriterioPeso
Claridad del problema y justificación15%
Calidad y preparación del dataset15%
Implementación y métricas del modelo25%
Análisis crítico (errores, limitaciones)20%
Consideraciones éticas15%
Calidad de la presentación10%

4. Errores frecuentes a corregir antes del lunes

Cuidado

Los proyectos con problemas más comunes son: evaluar con los datos de entrenamiento, no justificar la elección del algoritmo, omitir el análisis ético, y no tener un repositorio documentado.

  • No separar conjunto de prueba desde el inicio → todos los resultados son inflados.
  • Elegir el modelo con mayor exactitud sin analizar por qué → falta pensamiento crítico.
  • Mencionar ética solo en una oración → debe haber análisis real con subgrupos.
  • GitHub sin README → el proyecto no es reproducible.
