Clustering y K-Means

Sin etiquetas no hay supervisión, pero sí hay estructura oculta en los datos. El clustering descubre grupos naturales — clientes con comportamiento similar, documentos del mismo tema, genes con expresión parecida — sin necesitar que nadie los haya etiquetado antes.

Distinguir el aprendizaje no supervisado del supervisado.

1. Aprendizaje no supervisado

Nota

No hay etiquetas. El algoritmo encuentra estructura por sí solo: grupos (clustering), representaciones compactas (reducción de dimensiones) o reglas (asociación).

Aplicaciones: segmentación de clientes, detección de anomalías, compresión de datos.

2. K-Means paso a paso

  1. Elegir k centroides aleatoriamente.
  2. Asignar cada punto al centroide más cercano.
  3. Recalcular cada centroide como la media de sus puntos.
  4. Repetir 2-3 hasta convergencia.
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

km = KMeans(n_clusters=3, random_state=42, n_init=10)
km.fit(X)
etiquetas = km.labels_
centroides = km.cluster_centers_

plt.scatter(X[:,0], X[:,1], c=etiquetas, cmap='tab10', alpha=0.6)
plt.scatter(centroides[:,0], centroides[:,1], marker='X', s=200, c='red')
plt.title("Clusters K-Means"); plt.show()

3. Método del codo para elegir k

inercias = []
for k in range(1, 11):
    inercias.append(KMeans(n_clusters=k, n_init=10).fit(X).inertia_)
plt.plot(range(1, 11), inercias, 'o-'); plt.xlabel("k"); plt.ylabel("Inercia"); plt.show()

4. Métrica de silueta

Tip

El coeficiente de silueta mide qué tan bien encaja cada punto en su cluster (1=perfecto, 0=en el borde, -1=mal asignado). Se usa para validar objetivamente la calidad del clustering.

from sklearn.metrics import silhouette_score
print(f"Silueta: {silhouette_score(X, km.labels_):.3f}")
