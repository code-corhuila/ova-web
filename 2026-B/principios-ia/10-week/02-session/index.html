Análisis de Componentes Principales (PCA) — reducción de dimensiones

Más variables no siempre significa más información. PCA comprime datos de alta dimensión en unas pocas componentes que capturan la mayor varianza, reduciendo ruido, tiempo de cómputo y el efecto de la maldición de la dimensionalidad.

1. ¿Qué hace PCA?

Nota

PCA rota el espacio de variables para encontrar las componentes principales — nuevas variables ortogonales que capturan la máxima varianza. Las primeras componentes retienen la mayor información; las últimas (ruido) se descartan.

No se pierde información si se conservan todas las componentes; la ganancia viene de descartar las que aportan poco.

2. Implementación

from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

# PCA requiere datos escalados
X_s = StandardScaler().fit_transform(X)

pca = PCA(n_components=2)
X_2d = pca.fit_transform(X_s)

print("Varianza explicada:", pca.explained_variance_ratio_)
# e.g. [0.72, 0.15] → 87% de la varianza en 2 componentes

3. Elegir el número de componentes

pca_full = PCA().fit(X_s)
varianza_acum = pca_full.explained_variance_ratio_.cumsum()

import matplotlib.pyplot as plt
plt.plot(range(1, len(varianza_acum)+1), varianza_acum, 'o-')
plt.axhline(0.95, linestyle='--', color='red', label='95%')
plt.xlabel("Número de componentes"); plt.ylabel("Varianza acumulada")
plt.legend(); plt.show()
# Elegir el número mínimo que supera el umbral (p.ej. 95%)

4. PCA antes de entrenar

Tip

PCA como preprocesamiento reduce dimensiones, elimina correlaciones y acelera el entrenamiento — especialmente útil antes de kNN o SVM en datos de alta dimensión.

Pero: las componentes no son interpretables en términos de las variables originales.

5. Cuándo NO usar PCA

  • Cuando la interpretabilidad de las variables importa (e.g., modelos regulatorios).
  • Cuando las variables ya son pocas y no correlacionadas.
  • Como sustituto de selección de features con significado.
