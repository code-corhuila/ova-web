Integrar frontend y backend

Conecta el frontend con tu API real: login, listar y manejo de carga/error. Actividad opcional de refuerzo.

1

Consumir la API real con el token.

2

Manejar CORS, carga y error.

1. Enunciado

  1. Desde el frontend, haz login y guarda el token.
  2. Consume un endpoint protegido enviando el token y muestra los datos.
  3. Resuelve CORS y maneja carga/error.

2. Requisitos

  • Frontend integrado con la API (login + datos).

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `12-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 12" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
