Integración Frontend–Backend

Es el momento de unir las dos capas: el frontend consume la API real (login, listar, crear), maneja el token y los estados de carga y error, y resuelve el CORS. Aquí "nace" la aplicación fullstack completa.

1

Conectar el frontend con la API real.

2

Manejar token, carga y error en la UI.

3

Entender y resolver CORS.

1. La integración

Nota

El frontend deja de usar datos de ejemplo y consume tu API: inicia sesión (recibe el token), lo guarda y lo envía en cada petición, y muestra los datos. Es la unión de todo el curso.

[ Frontend SPA ]  ──login──►  [ API Spring Boot ]  ──►  [ BD ]
      │  guarda token
      └──GET /productos (Bearer token)──►  responde JSON  ──►  render

2. Consumir la API con el token

async function getProductos() {
  const token = localStorage.getItem("token");
  const res = await fetch("http://localhost:8080/productos", {
    headers: { Authorization: `Bearer ${token}` }
  });
  if (!res.ok) throw new Error("Error " + res.status);
  return res.json();
}

3. Estados de carga y error

Tip

Muestra cargando mientras llega la respuesta, los datos al llegar y un mensaje de error si falla (token vencido → 401, no existe → 404). Nunca dejes la pantalla en blanco.

const [estado, setEstado] = useState("cargando");
useEffect(() => {
  getProductos().then(setDatos).then(() => setEstado("ok"))
                .catch(() => setEstado("error"));
}, []);

4. CORS

Nota

CORS es una protección del navegador: por defecto bloquea que una página en un origen (p. ej. localhost:5173) llame a una API en otro (localhost:8080). Se resuelve habilitando CORS en el backend para el origen del frontend.

@CrossOrigin(origins = "http://localhost:5173")
@RestController
@RequestMapping("/productos")
public class ProductoController { /* ... */ }

5. Errores comunes

  • Olvidar enviar el token → 401 (no autorizado).
  • No habilitar CORS → el navegador bloquea la petición.
  • No manejar el error/carga (pantalla en blanco o congelada).
  • Quemar la URL del backend en muchos lugares (centralízala).
