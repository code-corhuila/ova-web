Repaso y evaluación del Corte 2

Cierre del Corte 2. Repasamos el backend: Spring Boot y arquitectura en capas, JPA (entity/repository), API REST (service/controller/endpoints) y la documentación/prueba con Swagger y Postman. Preparamos el parcial.

1. Mapa del corte

Spring Boot 3
   │
   ├─ Arquitectura en capas: controller → service → repository → entity
   ├─ JPA: entity (@Entity/@Id) + repository (JpaRepository) = CRUD
   ├─ API REST: GET/POST/PUT/DELETE, @RestController, @RequestBody
   └─ Documentar/probar: Swagger UI + Postman + códigos HTTP

2. Puntos clave para el parcial

Nota

Capas y su responsabilidad. JPA: cómo se mapea una tabla y qué da JpaRepository. REST: método HTTP correcto por acción, URLs con sustantivos, códigos de estado. Swagger/Postman: para qué sirven.

3. Checklist de repaso

  • Explico las 4 capas y qué hace cada una.
  • Creo una entity y su repository (CRUD sin SQL).
  • Diseño endpoints REST correctos (verbo HTTP, no en la URL).
  • Documento con Swagger y pruebo con Postman.
  • Interpreto 200/201/400/404/500.

4. Errores comunes a evitar

  • Lógica de negocio en el controller.
  • Verbos en las URLs REST.
  • No probar los errores (solo el camino feliz).
  • Entity sin @Entity/@Id.
