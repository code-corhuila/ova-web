Fundamentos web (HTML5, CSS3, JavaScript) y SPA vs MPA

Toda interfaz web se construye con tres lenguajes: HTML (estructura), CSS (apariencia) y JavaScript (comportamiento). En esta sesión los repasamos y entendemos la diferencia entre una aplicación de una sola página (SPA) y una de múltiples páginas (MPA).

1

Distinguir el rol de HTML, CSS y JavaScript.

2

Construir una interfaz básica.

3

Diferenciar SPA de MPA y cuándo usar cada una.

1. Los tres lenguajes del frontend

Nota

HTML define la estructura (qué hay), CSS define la apariencia (cómo se ve) y JavaScript define el comportamiento (qué hace). Los tres trabajan juntos en el navegador.

<h1>Productos</h1>
<button id="cargar">Cargar</button>
<ul id="lista"></ul>
button { background: #0e7c7b; color: white; padding: 8px 14px; }
li { padding: 6px 0; border-bottom: 1px solid #ddd; }
document.getElementById("cargar").addEventListener("click", () => {
  document.getElementById("lista").innerHTML = "<li>Cargado</li>";
});

2. HTML: la estructura

Etiquetas semánticas describen el contenido: header, nav, main, section, footer, además de h1..h6, p, ul/li, form, input, button.

Tip

Usa etiquetas semánticas (no todo div): mejora accesibilidad y SEO, y el código se entiende mejor.

3. CSS: la apariencia

Selectores (.clase, #id, elemento), el modelo de caja (margin, border, padding, content) y layout con Flexbox/Grid.

4. JavaScript: el comportamiento

Variables (let, const), funciones, manipulación del DOM y eventos (addEventListener). Más adelante lo usarás para pedir datos a una API.

5. SPA vs MPA

Nota

MPA (Multi Page Application): cada acción recarga una página nueva desde el servidor. SPA (Single Page Application): una sola página que actualiza su contenido con JavaScript sin recargar; pide datos a una API. Angular y React construyen SPAs.

MPASPA
NavegaciónRecarga páginasSin recargar (JS)
Velocidad percibidaMenorMayor tras la carga inicial
EjemplosSitios clásicosAngular, React

6. Errores comunes

  • Usar div para todo (perder la semántica).
  • Mezclar estructura, estilo y lógica en un solo lugar sin orden.
  • Creer que una SPA "no usa servidor": sí lo usa, vía API.
  • Olvidar que el CSS se hereda y se sobreescribe por especificidad.
