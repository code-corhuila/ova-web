1. Mapa del corte

Fullstack (frontend + backend + datos)
      │
      ├─ HTML (estructura) · CSS (apariencia) · JS (comportamiento)
      ├─ SPA vs MPA
      ├─ Mockup → interfaz
      ├─ Consumo de API (fetch, JSON, estados carga/datos/error)
      └─ Framework: componentes · estado · enrutamiento

2. Puntos clave para el parcial

Nota

Capas: frontend pide, backend responde vía API. Los 3 lenguajes: HTML/CSS/JS y sus roles. SPA vs MPA. HTTP: GET/POST/PUT/DELETE y JSON. Framework: componente, estado (re-render), router.

3. Checklist de repaso

  • Explico qué es fullstack y sus tres capas.
  • Distingo el rol de HTML, CSS y JavaScript.
  • Sé consumir una API con fetch y manejar carga/error.
  • Entiendo componente, estado y enrutamiento.
  • Uso Git para versionar y entregar por mi fork.

4. Errores comunes a evitar en el parcial

  • Confundir SPA con "sin servidor".
  • Olvidar el manejo de error/carga al consumir datos.
  • Mezclar responsabilidades (estructura/estilo/lógica) sin orden.
