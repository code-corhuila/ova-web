Unidad 3 · Práctica opcional (no calificable)

Limpieza con Power Query y esbozo de narrativa

Transforma un dataset desordenado y bosqueja una narrativa de 3 pasos antes de la actividad calificable A3.

1

Aplicar transformaciones de Power Query a datos desordenados y dejar el proceso repetible.

2

Esbozar una narrativa visual con estructura introducción–cuerpo–cierre.

1. Objetivo

Afianzar la transformación de datos y el pensamiento narrativo, como preparación para la actividad calificable A3 · Transformación de Datos con Power Query (25 %). Práctica opcional y no calificable.

2. Enunciado

  1. Toma un dataset desordenado (columnas mezcladas, fechas como texto, valores duplicados).
  2. En Power Query, aplica al menos: cambiar tipos, separar una columna por delimitador,

eliminar duplicados y reemplazar valores.

  1. Verifica que los pasos aplicados dejen el proceso repetible (se reaplica al refrescar).
  2. Con los datos limpios, esboza una narrativa de 3 pasos (introducción → cuerpo → cierre) que

podrías contar con ellos (en papel o en una hoja de Qlik/Power BI).

3. Requisitos mínimos

  • Al menos 4 transformaciones distintas en Power Query.
  • Lista de pasos aplicados documentada (captura).
  • Esbozo de narrativa con las 3 etapas y qué visual iría en cada una.

4. Entrega

  • Captura de los pasos aplicados + el archivo/enlace de datos limpios + el esbozo de la narrativa

(media página o un boceto).
