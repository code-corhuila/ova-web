De los datos al dashboard profesional con Power BI

1. Power BI: la navaja suiza del analista

Power BI permite extraer datos, transformarlos, analizarlos y visualizarlos en una sola herramienta. En esta unidad recorres el flujo completo, de principio a fin.

  FLUJO DE POWER BI
  Obtener → Transformar → Modelar → Medir → Visualizar
  (fuentes)  (Power Query) (relaciones) (DAX)   (dashboard)

Imagina que trabajas con los reportes de ventas de tu empresa: los datos están en Excel pero desordenados. Power BI te permite conectarte, limpiarlos, crear relaciones y visualizar todo en un tablero interactivo.

Fuentes de datos

Power BI se conecta a múltiples orígenes:

  • Archivos locales — Excel, CSV, TXT
  • Bases de datos — SQL Server, PostgreSQL, MySQL
  • Servicios en la nube — SharePoint, Google Analytics
  • APIs y Web

Tip

Ejemplo práctico — abre Power BI → Obtener datos → Excel → elige tu archivo → clic en Transformar datos para entrar a Power Query.

2. Limpieza y transformación con Power Query

Power Query es el editor de datos. Aquí preparas la información antes de modelarla:

  • Eliminar filas o columnas vacías.
  • Cambiar tipos de datos (texto, número, fecha).
  • Separar columnas por delimitador.
  • Reemplazar valores.
  • Crear columnas personalizadas.

Nota

Cada transformación queda registrada como un paso en Pasos aplicados: se puede deshacer, editar o reordenar. El proceso es repetible: al actualizar la fuente, se vuelven a aplicar todos los pasos automáticamente.

3. Modelado de datos

Una vez cargados, Power BI muestra las tablas como piezas de Lego: si las conectas bien con relaciones adecuadas, todo funciona sin errores.

  • Claves primarias y foráneas identifican y enlazan las tablas.
  • Relaciones uno a muchos (1:\*) son las más comunes (una fecha → muchas ventas).
  • Evita las relaciones circulares.
   Ventas ──(ID_producto)──► Productos
      │
      └──────(fecha)────────► Calendario

4. Cálculos con DAX (básico)

DAX (Data Analysis Expressions) es el lenguaje para crear medidas y columnas calculadas. Empieza por medidas simples antes de fórmulas complejas.

Total Ventas = SUM(Ventas[Valor])
Promedio por Cliente = AVERAGE(Ventas[Monto])
Ventas 2024 = CALCULATE(SUM(Ventas[Monto]), Ventas[Año] = 2024)
MedidaColumna calculada
Se calculaAl vuelo, según el contexto del gráficoFila por fila al cargar
Ocupa memoriaNo (se evalúa al usarse)Sí (se almacena)
Úsala paraAgregaciones (sumas, promedios, %)Atributos por fila (categorías, banderas)

5. KPIs: qué medir y cómo elegirlos

Un KPI (Key Performance Indicator / Indicador Clave de Desempeño) no es cualquier número: es una métrica estratégica que indica si se está alcanzando un objetivo.

Ejemplos: % de cumplimiento de metas de ventas · tiempo promedio de respuesta al cliente · tasa de rotación de personal.

Criterios para elegir un buen KPI:

  • Relevante para el objetivo del análisis.
  • Cuantificable.
  • Comprensible para el usuario final.
  • Actualizable con regularidad.

Tip

Ejercicio — elige 3 KPIs clave para un dashboard de atención en salud pública. Justifica por qué cada uno cumple los cuatro criterios.

6. Diseño de dashboards: más que juntar gráficos

Un dashboard efectivo tiene: un resumen visual (overview) que se ve primero, jerarquía visual (lo importante arriba), filtros accesibles (fecha, región, categoría) y estética consistente.

  ESTRUCTURA RECOMENDADA
  ┌───────────────────────────────────────────┐
  │ [ Tarjetas de resumen ]      ← KPI visual   │
  │ [ Gráfico de barras ]        ← comparación  │
  │ [ Segmentadores por fecha ]  ← filtro       │
  │ [ Mapa o matriz ]            ← detalle       │
  └───────────────────────────────────────────┘

Buenas prácticas vs antipatrones

Sí (buenas prácticas)Evita (antipatrones)
Títulos claros ("Ventas por producto – 2023")Más de 6 colores distintos en un gráfico
Paleta de colores coherenteGráficos 3D o decorativos innecesarios
Elementos alineados en rejillaVisualizaciones densas (burbujas de 4 dimensiones)
Temas, segmentadores, gráficos combinadosSobrecargar el tablero con gráficos que nadie usa

7. Caso aplicado: dashboard de control de proyectos

Eres parte del equipo de proyectos de una ONG y necesitas mostrar: número total de proyectos activos, avance promedio (%), proyectos retrasados (semáforo) y presupuesto ejecutado vs aprobado.
