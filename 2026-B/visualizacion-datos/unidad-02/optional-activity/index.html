Mini-dashboard en Power BI con KPIs

Construye un mini-dashboard para practicar el flujo completo de Power BI antes de la actividad calificable A2.

1

Recorrer el flujo de Power BI (obtener, transformar, modelar, medir, visualizar) con un dataset propio.

2

Definir 3 KPIs pertinentes y una medida DAX básica.

1. Objetivo

Practicar el flujo completo de Power BI en pequeño, para llegar con soltura a la actividad calificable A2 · Dashboard Completo (25 %). Práctica opcional y no calificable.

2. Enunciado

  1. Toma un dataset sencillo (el sales data raw del aula, o uno propio en Excel/CSV).
  2. Obtén los datos y límpialos en Power Query (tipos, columnas vacías, duplicados).
  3. Crea una relación entre dos tablas si aplica (p. ej. ventas ↔ calendario).
  4. Define 3 KPIs y al menos una medida DAX (por ejemplo Total Ventas = SUM(...)).
  5. Arma un mini-dashboard con tarjetas de KPI + un gráfico de barras + un segmentador.

3. Requisitos mínimos

  • Datos limpios en Power Query (pasos aplicados visibles).
  • 3 KPIs con justificación (por qué son relevantes, cuantificables, comprensibles).
  • 1 medida DAX funcionando.
  • Jerarquía visual: KPIs arriba, detalle abajo.
  • Paleta coherente (máx. 4 colores) y títulos claros.

4. Entrega

  • Captura del dashboard + el archivo .pbix (o enlace) y una nota breve (máx. media página)

explicando los 3 KPIs y la medida DAX.
