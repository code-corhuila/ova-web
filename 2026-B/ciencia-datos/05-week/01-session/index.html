1. Mapa del Corte 1

Semana 1  Introducción a la ciencia de datos (proceso, dato→conocimiento)

Semana 4  Aplicaciones (analítica descriptiva→prescriptiva, ML, ética)
Semana 5  Repaso + Evaluación Corte 1

2. Síntesis

  • Ciencia de datos: estadística + programación + ML + dominio → decisiones.
  • Proceso: pregunta → datos → limpieza → análisis → modelo → comunicación → acción.
  • Big Data: las V (volumen, velocidad, variedad, veracidad, valor); datos estructurados/semi/no estructurados.
  • Ecosistema: data lake (crudo) vs warehouse (procesado); batch vs streaming; Hadoop/Spark/Kafka/Airflow/dbt.
  • Analítica: descriptiva → diagnóstica → predictiva → prescriptiva; ML supervisado/no supervisado; ética y sesgos.

3. Preguntas tipo Saber PRO (con razonamiento)

1) Una empresa quiere saber por qué subieron los defectos. ¿Qué analítica? Diagnóstica.

2) Clasifica: lecturas de un sensor en CSV / fotos de piezas / un JSON de un API. Estructurado / no estructurado / semiestructurado.

3) ¿Lake o warehouse para explorar datos crudos variados? Data lake.

4) ¿Batch o streaming para alertar fallas al instante? Streaming.

5) ¿Por qué la limpieza es crítica? "Basura entra, basura sale": datos sucios → decisiones malas.

Cuidado

En el parcial se evalúa el criterio (elegir y justificar), no solo definiciones.

4. Preparación

  • Modalidad: individual, teórico‑práctica. Temas: semanas 1–4.
  • Ten claras las V, los tipos de datos, lake vs warehouse y los tipos de analítica.
