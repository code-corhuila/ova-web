Dossier de fundamentos (cierre C1)

Reúne lo del Corte 1 en un dossier del proyecto de datos de tu caso. Actividad opcional de refuerzo.

1

Integrar el encuadre de un proyecto de datos.

2

Consolidar fundamentos de Big Data y analítica.

1. Enunciado

Arma un dossier (README + anexos) que reúna, mejorado, lo del corte:

  1. Pregunta de negocio + decisión esperada (S1).
  2. Fuentes y clasificación de datos + V relevantes (S2).
  3. Arquitectura de datos propuesta (S3).
  4. Tipos de analítica objetivo + un riesgo ético (S4).

2. Requisitos

  • README que organice las 4 partes con coherencia.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `05-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 05" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
