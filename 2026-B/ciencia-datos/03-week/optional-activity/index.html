Diseña una arquitectura de datos

Traza el flujo de datos de tu caso, de las fuentes al BI. Actividad opcional de refuerzo.

1

Diseñar el flujo fuentes → BI.

2

Elegir lake/warehouse y batch/streaming con criterio.

1. Enunciado

  1. Dibuja (diagrama o ASCII) la arquitectura: fuentes → ingesta → almacenamiento → procesamiento → análisis/BI.
  2. Justifica: ¿data lake o warehouse? ¿batch o streaming?
  3. Nombra una herramienta candidata por etapa (ingesta, procesamiento, BI) y por qué.

2. Requisitos

  • Diagrama del flujo completo.
  • Decisiones lake/warehouse y batch/streaming justificadas.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `03-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 03" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
