Tipos de analítica y ética

Clasifica preguntas por tipo de analítica y reflexiona sobre riesgos éticos. Actividad opcional de refuerzo.

1

Clasificar analítica descriptiva/diagnóstica/predictiva/prescriptiva.

2

Identificar riesgos éticos y de sesgo.

1. Enunciado

  1. Escribe 4 preguntas sobre tu caso, una por cada tipo de analítica (descriptiva, diagnóstica, predictiva, prescriptiva).
  2. Indica para la predictiva/prescriptiva si usarías ML supervisado o no supervisado y por qué.
  3. Describe un posible sesgo o riesgo ético y cómo mitigarlo.

2. Requisitos

  • 4 preguntas bien clasificadas.
  • Riesgo ético + mitigación.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `04-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 04" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
