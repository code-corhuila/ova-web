Optimiza una consulta o crea medidas

Mejora una consulta lenta o crea métricas con DAX. Actividad opcional de refuerzo.

1

Aplicar buenas prácticas de eficiencia.

2

Argumentar la mejora.

1. Enunciado

Elige una opción:

  • A) SQL: toma una consulta lenta (SELECT *, función en el WHERE) y reescríbela (columnas necesarias, filtro por rango, índice). Explica la mejora.
  • B) DAX: en Power BI crea 2 medidas (p. ej. Total y % del total, o comparación entre periodos) y descríbelas.

2. Requisitos

  • Consulta/medidas antes y después + explicación de por qué mejora.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `14-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 14" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
