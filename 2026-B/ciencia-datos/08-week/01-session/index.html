Conexión de datos: APIs, ETL y pipelines

Los datos viven en muchos lugares; hay que traerlos, transformarlos y dejarlos listos para analizar. Esta sesión explica cómo consumir datos de APIs y cómo funciona un proceso ETL y los pipelines modernos que lo orquestan (Airflow, n8n, Kafka).

1

Consumir datos desde una API (JSON).

2

Explicar el proceso ETL (extraer, transformar, cargar).

3

Distinguir orquestación (Airflow/n8n) de streaming (Kafka).

4

Reconocer un pipeline de datos de extremo a extremo.

1. Datos desde una API

Nota

Una API entrega datos bajo demanda, normalmente en JSON, mediante peticiones HTTP. Es una fuente común para enriquecer o alimentar análisis.

import requests
r = requests.get("https://api.ejemplo.com/ventas")
datos = r.json()      # lista de registros (JSON)

2. ETL: extraer, transformar, cargar

Nota

ETL = Extraer datos de las fuentes → Transformarlos (limpiar, unir, calcular) → Cargarlos en el destino (almacén). Es la columna vertebral de la preparación de datos. (Variante moderna: ELT, se carga primero y se transforma en el almacén.)

Fuentes (BD, API, CSV) → [Extraer] → [Transformar] → [Cargar] → Data Warehouse → BI

3. Pipelines y orquestación

Un pipeline encadena pasos de datos que corren automáticamente. La orquestación decide el orden, los horarios y qué hacer si algo falla.

HerramientaRol
AirflowOrquestar flujos programados (ETL por lotes)
n8nAutomatizar flujos con poco código (conectores)
KafkaTransportar eventos en tiempo real (streaming)

Nota

Airflow/n8n orquestan (¿qué corre y cuándo?); Kafka transporta flujos continuos de eventos. Se complementan.

4. Un pipeline de extremo a extremo

Sensores/API → Kafka (ingesta) → Transformación (Python/dbt)
   → Data Warehouse → Power BI (tablero)   [orquestado por Airflow]

5. Errores comunes

  • Hacer ETL "a mano" repetidamente en vez de automatizar un pipeline.
  • No manejar fallos (si una fuente cae, el flujo debe reintentar/avisar).
  • Cargar datos sin transformarlos ni validarlos.
  • Usar streaming (Kafka) cuando bastaba un ETL por lotes.
