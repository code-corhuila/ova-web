Diseña un pipeline ETL

Traza un flujo ETL para tu caso y (opcional) prueba consumir una API. Actividad opcional de refuerzo.

1

Diseñar un flujo ETL de extremo a extremo.

2

Consumir datos de una API.

1. Enunciado

  1. Diseña (diagrama) un pipeline ETL para tu caso: fuentes → extraer → transformar → cargar → BI, indicando herramienta por paso.
  2. Indica qué partes serían batch y cuáles streaming, y por qué.
  3. (Opcional) En Python, consume una API pública con requests y muestra 3 registros.

2. Requisitos

  • Diagrama del pipeline con herramientas por etapa.
  • Justificación batch/streaming.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `08-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 08" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
