Análisis de una serie de tiempo

Analiza una serie temporal real con Python: agrégala, suavízala y describe su comportamiento. Actividad opcional de refuerzo.

1

Manejar fechas y agregación temporal.

2

Calcular una media móvil e interpretarla.

1. Enunciado

  1. Toma una serie temporal (ventas/producción/temperatura, real o simulada) y cárgala en Python (pandas) con la fecha como índice.
  2. Agrégala por mes (resample) y calcula una media móvil (rolling).
  3. Describe tendencia y estacionalidad que observes (2–3 líneas).

2. Requisitos

  • Script + un gráfico de la serie con su media móvil.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `11-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 11" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
