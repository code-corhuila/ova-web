Análisis temporal y series de tiempo

Muchos datos industriales tienen una dimensión temporal: producción por día, temperatura por hora, ventas por mes. Esta sesión introduce el análisis temporal —tendencia, estacionalidad y funciones de fecha— y una primera mirada al pronóstico con series de tiempo en Python.

1

Manejar fechas y jerarquías de tiempo.

2

Distinguir tendencia, estacionalidad y ruido.

3

Calcular métricas móviles (medias móviles).

4

Reconocer la idea de pronóstico de series de tiempo.

1. El tiempo como dimensión

Nota

Una serie de tiempo es una secuencia de valores ordenados por fecha/hora (p. ej. producción diaria). Permite ver cómo evoluciona algo y anticipar su comportamiento.

Las fechas tienen jerarquías (año → trimestre → mes → día → hora) que permiten agregar y comparar a distintos niveles.

2. Componentes de una serie

Nota

Tendencia: dirección de largo plazo (sube/baja). Estacionalidad: patrones que se repiten (más ventas en diciembre). Ruido: variación aleatoria.

valor
  |        /\    /\      tendencia ↗ + estacionalidad (picos) + ruido
  |   /\  /  \  /  \
  |__/__\/____\/____\____ tiempo

3. Trabajar fechas en Python (pandas)

import pandas as pd
df = pd.read_csv("produccion.csv", parse_dates=["fecha"])
df = df.set_index("fecha")
mensual = df["unidades"].resample("M").sum()   # agregar por mes
df["movil7"] = df["unidades"].rolling(7).mean()  # promedio de 7 días

Nota

resample agrega por periodo (día/mes/año); la media móvil (rolling) suaviza el ruido para ver la tendencia.

4. Pronóstico: la idea

Con la historia se puede estimar el futuro (demanda del próximo mes, carga de una máquina). Existen métodos desde promedios y suavizado hasta modelos como ARIMA o Prophet. La clave: separar tendencia y estacionalidad para proyectarlas.

Tip

Un pronóstico se evalúa comparándolo con datos reales que el modelo no vio (validación); nunca con los mismos datos de entrenamiento.

5. Errores comunes

  • Analizar la fecha como texto (no como fecha) → no se puede agregar por periodo.
  • Ignorar la estacionalidad (comparar diciembre con febrero sin ajustar).
  • Evaluar el pronóstico con los mismos datos de entrenamiento.
  • Extrapolar muy lejos sin incertidumbre.
