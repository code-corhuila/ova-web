1. SQL: consultar datos relacionales

Nota

SQL es el lenguaje para consultar bases relacionales. Con pocas cláusulas resuelves la mayoría de preguntas.

SELECT nombre, ciudad
FROM cliente
WHERE ciudad = 'Neiva';
SELECT c.nombre, p.fecha
FROM cliente c
JOIN pedido p ON p.id_cliente = c.id_cliente;
SELECT ciudad, COUNT(*) AS total
FROM cliente
GROUP BY ciudad;

Nota

WHERE filtra filas, JOIN combina tablas por sus claves, GROUP BY agrupa para agregar (COUNT, SUM, AVG).

2. NoSQL: consultar documentos (MongoDB)

db.clientes.find({ ciudad: "Neiva" })
db.pedidos.aggregate([{ $group: { _id: "$ciudad", total: { $sum: 1 } } }])

En NoSQL los datos son documentos (JSON); se consulta por campos y se agrega con pipelines.

3. Python (pandas) para análisis

Nota

pandas es la librería de Python para datos tabulares: carga CSV/Excel/SQL y permite filtrar, agrupar y analizar con pocas líneas.

import pandas as pd
df = pd.read_csv("clientes.csv")
print(df.head())                 # primeras filas
neiva = df[df["ciudad"] == "Neiva"]   # filtrar
print(df.groupby("ciudad").size())    # agrupar/contar

4. ¿Y dbt?

dbt transforma datos dentro del almacén con SQL versionado y probado (aplica transformaciones reproducibles). Es el "T" de ETL hecho con buenas prácticas de ingeniería.

6. Errores comunes

  • Traer TODA la tabla a Python cuando SQL ya podía filtrar/agrupar.
  • Olvidar el ON en un JOIN (produce un producto cartesiano enorme).
  • Confundir WHERE (filtra filas) con HAVING (filtra grupos).
  • Analizar sin revisar tipos y nulos primero.
