Mini-proyecto de datos (cierre C2)

Integra modelamiento, consultas y limpieza en un mini-proyecto de datos. Actividad opcional de refuerzo.

1

Integrar modelo, consultas y limpieza.

2

Dejar los datos listos para analizar.

1. Enunciado

Sobre tu caso, integra lo del corte:

  1. Modelo de datos (ERD).
  2. Carga un dataset (CSV/API) y límpialo en pandas.
  3. Responde 2 preguntas con consultas (SQL o pandas: filtro + agregación).
  4. Deja los datos listos y documenta el flujo (extraer → limpiar → analizar).

2. Requisitos

  • Datos limpios + 2 análisis con consultas.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `10-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 10" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
