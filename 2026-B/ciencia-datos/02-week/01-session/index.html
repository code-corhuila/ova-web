Fundamentos de Big Data

Cuando los datos crecen tanto que las herramientas tradicionales no bastan, hablamos de Big Data. Esta sesión explica qué lo caracteriza (las V), los tipos de datos y por qué exige nuevas formas de almacenar y procesar.

1. ¿Qué es Big Data?

Nota

Big Data. Conjuntos de datos tan grandes, rápidos o variados que superan la capacidad de las herramientas tradicionales (una hoja de cálculo, una base de datos única) y requieren tecnologías distribuidas para almacenarlos y analizarlos.

2. Las "V" del Big Data

VSignificadoEjemplo industrial
VolumenCantidad enorme de datosSensores de una planta 24/7
VelocidadDatos que llegan en tiempo realTelemetría de máquinas
VariedadFormatos diversosNúmeros, texto, imágenes, logs
VeracidadCalidad/confiabilidadLecturas con ruido o faltantes
ValorUtilidad para decidirPredecir una falla a tiempo

Tip

No todo dato grande es "Big Data". Lo define el reto: cuando volumen + velocidad + variedad rompen las herramientas normales.

3. Tipos de datos

Nota

Estructurados: tablas con filas y columnas (una base de datos, un CSV). Semiestructurados: con estructura flexible (JSON, XML). No estructurados: sin formato fijo (texto libre, imágenes, audio, video).

Estructurado (tabla)   Semiestructurado (JSON)   No estructurado (imagen/texto)
 id | temp | maq         {"maq":3,"temp":35}        "la máquina hace ruido..."

4. ¿Por qué importa en la industria?

Sensores, líneas de producción y sistemas generan datos masivos y continuos. Aprovecharlos permite anticipar fallas, optimizar procesos y reducir costos; ignorarlos es desperdiciar información valiosa.

5. Errores comunes

  • Llamar "Big Data" a cualquier archivo grande.
  • Ignorar la veracidad: analizar datos sucios lleva a decisiones malas.
  • Guardar todo "por si acaso" sin un objetivo (costos sin valor).
  • Olvidar la privacidad y el buen manejo de datos sensibles.
