Rediseña un gráfico

Encuentra (o crea) un gráfico deficiente y redisénalo aplicando los principios de visualización efectiva. Actividad opcional de refuerzo.

1

Aplicar principios de visualización.

2

Justificar decisiones de diseño.

1. Enunciado

  1. Elige un gráfico mal hecho (eje truncado, torta saturada, 3D, sin título…) o crea uno.
  2. Redisénalo aplicando los principios: gráfico correcto, escala honesta, título con conclusión, color con propósito.
  3. Explica en 3–4 líneas qué mejoraste y por qué.

2. Requisitos

  • Antes/después (imágenes) + justificación.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `12-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 12" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
