ERD de tu caso

Diseña el modelo de datos de tu proyecto con un ERD. Actividad opcional de refuerzo.

1

Modelar entidades, PK/FK y relaciones.

2

Aplicar normalización básica.

1. Enunciado

  1. Diseña el ERD de tu caso con al menos 3 entidades, sus PK/FK y relaciones (incluye una N:M con tabla intermedia).
  2. Justifica si usarías enfoque relacional o NoSQL y por qué.
  3. Señala dónde aplicaste normalización (qué evitaste repetir).

2. Requisitos

  • ERD con PK/FK y una relación N:M.
  • Decisión relacional/NoSQL justificada.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `06-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 06" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
