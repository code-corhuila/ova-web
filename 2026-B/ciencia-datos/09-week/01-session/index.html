Transformación y calidad de datos

Los datos reales llegan sucios: faltantes, duplicados, formatos inconsistentes. Antes de analizar hay que limpiarlos. Esta sesión enseña las tareas típicas de limpieza y calidad de datos con Python (pandas), el paso que más impacta en un buen resultado.

1. Datos sucios: el problema real

Nota

"Basura entra, basura sale." La calidad del análisis depende de la calidad de los datos. La limpieza suele consumir la mayor parte del tiempo de un proyecto.

Problemas típicos: valores faltantes, duplicados, tipos incorrectos (números como texto), formatos inconsistentes ("Neiva" vs "neiva "), y atípicos (outliers).

2. Faltantes y duplicados (pandas)

import pandas as pd
df = pd.read_csv("ventas.csv")
print(df.isnull().sum())        # cuántos nulos por columna
df = df.dropna(subset=["precio"])   # quitar filas sin precio
df["ciudad"] = df["ciudad"].fillna("desconocida")  # imputar
df = df.drop_duplicates()               # quitar duplicados
df["fecha"] = pd.to_datetime(df["fecha"])   # texto -> fecha
df["precio"] = pd.to_numeric(df["precio"])  # texto -> número

3. Normalizar formatos

df["ciudad"] = df["ciudad"].str.strip().str.title()  # "  neiva " -> "Neiva"

Tip

Define reglas claras: una sola forma de escribir cada categoría, un formato de fecha, unidades consistentes. La consistencia evita errores en el análisis.

Unicidad¿Hay duplicados?
Vigencia¿Están actualizados?

5. Errores comunes

  • Analizar sin revisar nulos ni tipos primero.
  • Eliminar filas con faltantes sin pensar (a veces conviene imputar).
  • No documentar las transformaciones (no es reproducible).
  • Ignorar los outliers (pueden ser errores o hallazgos).
