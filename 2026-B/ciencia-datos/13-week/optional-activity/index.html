Diseña un dashboard

Diseña el boceto de un dashboard para un proceso industrial: define KPIs, gráficos y filtros. Actividad opcional de refuerzo.

1

Definir KPIs relevantes.

2

Estructurar un tablero claro.

1. Enunciado

  1. Elige un proceso (producción, calidad, ventas) y define 3 KPIs con su objetivo.
  2. Boceta el dashboard: qué gráfico va con cada KPI y qué filtros tendrá (fecha, planta, producto).
  3. Justifica el orden/jerarquía visual (qué va arriba y por qué).

2. Requisitos

  • Boceto (imagen o Power BI/figura) + lista de KPIs y filtros.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `13-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 13" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
