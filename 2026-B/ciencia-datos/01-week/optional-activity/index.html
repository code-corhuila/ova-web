Encuadra un proyecto de datos

Practica el paso más importante: convertir un problema real en un proyecto de datos bien planteado. Actividad opcional de refuerzo.

1

Formular una pregunta de negocio clara.

2

Identificar datos y decisión esperada.

1. Enunciado

  1. Elige un problema real (industria/servicios) y formúlalo como pregunta de negocio.
  2. Indica qué datos necesitarías y de qué fuentes.
  3. Describe la decisión o acción que habilitaría el resultado.
  4. Clasifica el tipo de analítica que buscas (descriptiva/predictiva/…).

2. Requisitos

  • Pregunta clara + datos/fuentes + decisión esperada.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `01-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 01" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
