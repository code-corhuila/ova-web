Haz interactivo tu dashboard

Convierte gráficos sueltos en un tablero que se explora. Practica segmentadores, filtrado cruzado y drill-down sobre tu proyecto. Actividad opcional de refuerzo.

1

Añadir segmentadores y jerarquías.

2

Verificar el filtrado cruzado.

1. Enunciado

Sobre tu dashboard del proyecto (o uno de práctica):

  1. Agrega al menos dos segmentadores por dimensiones útiles (p. ej. año y región).
  2. Crea una jerarquía con drill-down (p. ej. Año → Trimestre → Mes).
  3. Verifica el filtrado cruzado haciendo clic en un visual y observando el resto.
  4. Captura dos estados del tablero (sin filtro y filtrado) y comenta la diferencia.

2. Requisitos

  • Dos segmentadores funcionales.
  • Una jerarquía con drill-down.
  • Evidencia del filtrado cruzado.
  • Capturas comparadas.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `12-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 12" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
