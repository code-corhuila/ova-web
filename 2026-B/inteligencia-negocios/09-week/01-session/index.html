Introducción a los cálculos — medidas básicas (DAX)

Un modelo limpio todavía no responde preguntas: hay que calcular. Esta sesión introduce DAX, el lenguaje de cálculo de Power BI, y sus medidas básicas —sumas, promedios y conteos— además de la diferencia clave entre una medida y una columna calculada.

1. ¿Qué es DAX?

Nota

DAX (Data Analysis Expressions). Lenguaje de fórmulas de Power BI para crear cálculos sobre el modelo: totales, promedios, porcentajes, indicadores. Se parece a las fórmulas de Excel, pero opera sobre tablas y relaciones, no sobre celdas.

Con el modelo estrella ya cargado y limpio, DAX es lo que convierte esas tablas en respuestas: ¿cuánto vendimos?, ¿cuál es el ticket promedio?, ¿cuántos clientes distintos compraron?.

2. Medida vs. columna calculada

Esta distinción es la que más confunde y la más importante:

MedidaColumna calculada
Cuándo se calculaAl vuelo, según el filtro del tableroUna vez, al cargar
Dónde vive el resultadoEn el visual (no ocupa la tabla)Como una columna más
Para quéAgregaciones (sumar, promediar)Valor por fila (clasificar)
EjemploVentas Totales = SUM(...)Margen = [precio] - [costo]

Tip

Regla práctica: si vas a sumar, promediar o contar, crea una medida. Si necesitas un valor fila por fila para filtrar o agrupar, usa una columna (mejor aún, créala en Power Query). Ante la duda, medida.

3. Las medidas básicas

Con estas cuatro resuelves gran parte de un tablero. Se escriben en Nueva medida:

Ventas Totales = SUM ( Hechos[total] )
Ticket Promedio = AVERAGE ( Hechos[total] )
Cantidad Vendida = SUM ( Hechos[cantidad] )
Nº de Ventas = COUNTROWS ( Hechos )
Clientes Distintos = DISTINCTCOUNT ( Hechos[id_cliente] )

Nota

SUM suma, AVERAGE promedia, COUNTROWS cuenta filas, DISTINCTCOUNT cuenta valores únicos. Todas reciben una columna (o tabla) del modelo y devuelven un número que se recalcula según el contexto.

4. El contexto de filtro (la idea clave)

Nota

Contexto de filtro. Una medida no da un valor fijo: da el valor para lo que está filtrado en ese momento. La misma medida Ventas Totales muestra el total general en una tarjeta, y el total de cada categoría cuando la pones en una tabla por categoría.

  Medida:  Ventas Totales = SUM(Hechos[total])

  En una tarjeta            →  1.250.000   (todo)
  En tabla por categoría:
     Periféricos            →    340.000
     Pantallas              →    910.000   ← misma medida, distinto contexto

Esta es la potencia del modelo dimensional + DAX: escribes la medida una vez y ella se adapta a cada corte (por tiempo, producto, tienda) sin reescribir nada.

5. Una medida derivada sencilla

Las medidas pueden apoyarse en otras:

Ventas Totales = SUM ( Hechos[total] )

Ventas Promedio por Venta = DIVIDE ( [Ventas Totales], [Nº de Ventas] )

Tip

Usa DIVIDE en vez de /: maneja solo la división por cero (devuelve vacío en vez de error).

6. Errores comunes

  • Crear columnas calculadas para lo que debería ser una medida (infla el modelo y da totales mal).
  • Escribir la lógica de negocio en muchos visuales en vez de en una medida reutilizable.
  • Olvidar que una medida depende del contexto: "¿por qué da otro número?" casi siempre es el filtro.
  • Dividir con / y romperse ante un cero, en vez de usar DIVIDE.
