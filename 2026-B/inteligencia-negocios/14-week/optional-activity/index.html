Publica y comparte tu informe

Un tablero solo sirve si llega a quien decide, de forma segura y actualizada. Practica la publicación y el diseño móvil. Actividad opcional de refuerzo.

1

Publicar/compartir un informe con criterio de seguridad.

2

Diseñar la vista móvil.

1. Enunciado

  1. Publica tu informe en el servicio de Power BI (o documenta paso a paso el proceso si no tienes cuenta institucional).
  2. Define con quién lo compartirías, con qué permisos y por qué (criterio de seguridad).
  3. Configura o describe la actualización de datos (manual/programada; menciona gateway si aplica).
  4. Diseña la vista móvil priorizando KPIs y controles tocables; captura el resultado.

2. Requisitos

  • Informe publicado o proceso documentado.
  • Plan de compartición con permisos justificados.
  • Estrategia de actualización.
  • Vista móvil diseñada.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `14-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 14" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
