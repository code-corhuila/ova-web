OLTP u OLAP — clasifica y justifica

Aprende a reconocer, ante cualquier sistema, si estás en el mundo de la operación o el del análisis. Actividad opcional de refuerzo.

1

Clasificar sistemas reales como OLTP u OLAP.

2

Formular una pregunta analítica que requiera un data warehouse.

1. Enunciado

  1. Elige dos sistemas reales que conozcas (ej.: facturación, matrícula, inventario, un reporte gerencial) y clasifícalos como OLTP u OLAP, justificando en cada caso.
  2. Para uno de ellos, formula una pregunta de análisis (histórica, agregada) que NO convenga responder sobre la base operativa.
  3. Explica por qué llevar esos datos a un data warehouse mejora la respuesta (rendimiento, estructura o histórico).
  4. Dibuja el flujo OLTP → ETL → warehouse → reporte para tu caso.

2. Requisitos

  • Dos sistemas clasificados y justificados.
  • Una pregunta analítica bien formulada.
  • Justificación del data warehouse.
  • Diagrama del flujo.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `03-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 03" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
