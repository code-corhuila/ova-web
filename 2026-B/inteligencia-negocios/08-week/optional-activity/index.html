Limpia un dataset real con Power Query

La limpieza es el corazón del ETL. Toma datos reales y sucios y conviértelos en una tabla confiable, documentando tu receta. Actividad opcional de refuerzo.

1

Diagnosticar problemas de calidad de datos.

2

Aplicar transformaciones de limpieza repetibles.

1. Enunciado

  1. Descarga un dataset público sucio (por ejemplo del portal de Datos Abiertos de Colombia).
  2. En Power Query, aplica al menos cuatro transformaciones distintas (tipos, duplicados, texto, columna condicional, unpivot, filtros...).
  3. Documenta la lista de pasos aplicados (tu receta) y muestra el antes/después.
  4. Explica qué problema de calidad resolvió cada transformación.

2. Requisitos

  • Dataset público de origen (enlace o archivo).
  • Cuatro o más transformaciones aplicadas.
  • Receta de pasos documentada + antes/después.
  • Explicación de cada transformación.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `08-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 08" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
