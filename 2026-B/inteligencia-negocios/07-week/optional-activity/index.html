Conecta y combina fuentes con Power Query

Da tus primeros pasos prácticos con Power Query: conectar a datos reales y unir varios archivos en una sola tabla. Actividad opcional de refuerzo.

1

Conectar Power Query a fuentes CSV/Excel.

2

Combinar varios archivos de una carpeta.

1. Enunciado

  1. Consigue o crea dos o tres archivos CSV/Excel con la misma estructura (p. ej. ventas de meses distintos).
  2. En Power BI, conéctalos con Obtener datos y únelos con Combinar carpeta.
  3. Captura el panel de Pasos aplicados resultante.
  4. Explica en pocas líneas cómo entraría un archivo nuevo del mes siguiente sin rehacer el trabajo.

2. Requisitos

  • Dos o tres archivos con la misma estructura.
  • Combinación en una sola tabla con Power Query.
  • Captura de los pasos aplicados.
  • Explicación del refresco con datos nuevos.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `07-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 07" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
