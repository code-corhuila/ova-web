ETL moderno con Power Query (I) — conexión y extracción

Empieza la parte más práctica del curso. Esta sesión introduce el proceso ETL y su etapa de extracción con Power Query: conectar sin código a archivos CSV y Excel, entender el editor y combinar todos los archivos de una carpeta en una sola tabla.

1. ETL: el puente entre los datos y el análisis

Nota

ETL (Extract, Transform, Load). Proceso que extrae datos de sus fuentes, los transforma (limpia, normaliza, combina) y los carga en el destino (el modelo). Es lo que convierte datos dispersos y sucios en una tabla lista para analizar.

  EXTRACT              TRANSFORM                LOAD
  ───────              ─────────                ────
  Conectar y leer  →   Limpiar, convertir,  →   Cargar al modelo
  la fuente            unir, dar formato        (Power BI / Excel)
  (CSV, Excel,         (Semana 8)
   carpeta, BD)

Esta semana nos centramos en Extract; la transformación es la Semana 8.

2. ¿Qué es Power Query?

Nota

Power Query. Herramienta de ETL sin código integrada en Power BI y Excel. Permite conectar, limpiar y combinar datos mediante una interfaz visual: cada acción queda registrada como un paso repetible. Cuando lleguen datos nuevos, basta con actualizar y todos los pasos se reaplican solos.

Esa es su magia: haces la limpieza una vez y se repite automáticamente cada mes. Nada de rehacer el trabajo a mano.

3. Conectar a las fuentes

Desde Power BI: Inicio → Obtener datos. Las fuentes más comunes en el curso:

FuenteCuándoCómo
CSV / TextoExportaciones de sistemasObtener datos → Texto/CSV
ExcelPlanillas de la organizaciónObtener datos → Libro de Excel
CarpetaMuchos archivos igualesObtener datos → Carpeta
Base de datosDatos operativos (OLTP)Obtener datos → SQL Server

Nota

CSV (valores separados por comas) es el formato de intercambio más común: la primera fila son los encabezados y cada fila siguiente es un registro. Ojo con el separador (coma, punto y coma o tabulador) y la codificación (UTF-8) al conectar.

4. El editor de Power Query

Al conectar, se abre el Editor de Power Query. Sus partes:

  ┌───────────┬─────────────────────────┬──────────────────┐
  │ CONSULTAS │   VISTA DE DATOS         │ CONFIG. CONSULTA │
  │ (queries) │  (la tabla en progreso) │  Propiedades     │
  │ ventas    │  id | producto | total  │  PASOS APLICADOS │
  │ clientes  │  1  | Teclado  | 90000  │   • Origen       │
  │           │  2  | Monitor  | 320000 │   • Encabezados  │
  │           │                         │   • Tipos        │
  └───────────┴─────────────────────────┴──────────────────┘

Tip

El panel Pasos aplicados (derecha) es el corazón de Power Query: es la receta de tu ETL. Cada clic agrega un paso; puedes volver atrás, editar o borrar cualquiera. Esa receta es lo que se reejecuta al actualizar.

5. Combinar archivos de una carpeta

Un caso clásico: tienes ventas-enero.csv, ventas-febrero.csv… uno por mes. En vez de pegarlos a mano:

  1. Obtener datos → Carpeta y selecciona la carpeta.
  2. Power Query lista todos los archivos.
  3. Pulsa Combinar y transformar: apila automáticamente todos en una sola tabla.
  4. Al llegar ventas-marzo.csv, solo pones el archivo en la carpeta y Actualizas: entra solo.

Tip

Este patrón "carpeta → combinar → actualizar" ahorra horas cada mes y elimina los errores de copiar y pegar.

6. Errores comunes

  • Ignorar el separador o la codificación y ver acentos rotos o columnas pegadas.
  • No revisar que la primera fila sean los encabezados (a veces hay títulos arriba).
  • Cargar los datos sucios directo al modelo sin pasar por Transform (Semana 8).
  • Pegar archivos a mano en vez de usar Combinar carpeta.
