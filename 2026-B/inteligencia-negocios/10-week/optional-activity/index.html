Preparación para el Parcial del Segundo Corte

Llega al parcial con el flujo ETL y las medidas dominados. Resume, practica un caso y autoevalúate. Actividad opcional de repaso.

1

Consolidar el flujo ETL y las medidas del Corte 2.

2

Resolver un caso de limpieza y cálculo.

1. Enunciado

  1. Elabora un resumen de una página del Corte 2: granularidad, ETL con Power Query (extract/transform/load) y medidas DAX.
  2. Resuelve este caso: te entregan un CSV de ventas con precios como texto, fechas mezcladas, duplicados y un mes por columna. Escribe la receta de transformaciones (en orden) y las medidas para responder: total de ventas y ticket promedio por categoría.
  3. Marca los temas que dominas y los que debes repasar.

2. Requisitos

  • Resumen de una página del Corte 2.
  • Receta de transformaciones ordenada para el caso.
  • Medidas propuestas correctas.
  • Autodiagnóstico honesto.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `10-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 10" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
