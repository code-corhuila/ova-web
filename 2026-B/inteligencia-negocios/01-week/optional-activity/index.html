Puesta a punto del entorno y expectativas

Deja listo tu entorno de trabajo para todo el curso y declara qué quieres lograr. Actividad opcional de arranque.

1

Instalar Power BI Desktop y verificar su funcionamiento.

2

Crear/confirmar tu cuenta de GitHub.

3

Declarar tus expectativas y un problema de datos de interés.

1. Enunciado

  1. Instala Power BI Desktop (gratuito, Windows) y ábrelo. Toma una captura de la pantalla de inicio.
  2. Crea o confirma tu cuenta de GitHub y verifica que puedes iniciar sesión.
  3. Escribe un párrafo (5–8 líneas): qué esperas aprender del curso y qué problema de datos de tu entorno te gustaría resolver con un dashboard.
  4. Identifica de dónde saldrían esos datos (una fuente real o plausible).

2. Requisitos

  • Captura de Power BI Desktop funcionando.
  • Usuario de GitHub activo.
  • Párrafo de expectativas + problema de datos + fuente.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `01-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 01" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
