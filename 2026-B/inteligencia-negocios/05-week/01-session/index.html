1. Qué se evalúa en el Corte 1

El parcial cubre las semanas 1 a 4 (Unidad 0 y Unidad 1). Estos son los ejes:

2. Mapa de repaso

  BI = datos → decisiones
       │
       ├─ Cadena: dato → información → conocimiento → decisión
       ├─ KPI = métrica atada a una meta
       ├─ Analítica: descriptiva · diagnóstica · predictiva · prescriptiva
       │
  OLTP (escribe, opera)  ──ETL──→  OLAP / Data Warehouse (lee, analiza)
       │
  Modelo estrella:
       HECHOS (medidas: sumar)  ←→  DIMENSIONES (atributos: agrupar)

3. Conceptos que más se preguntan

Nota

Dato vs. información: el contexto es lo que los separa. KPI: métrica con meta. OLTP escribe / OLAP lee. Data warehouse: base diseñada para analizar. Estrella: hechos (medidas) rodeados de dimensiones (atributos). Medida = se suma; atributo = se agrupa por él.

Tip

El error más frecuente del corte es confundir medida con atributo. Repite la prueba: ¿tiene sentido sumarlo? → medida (hechos). ¿tiene sentido agrupar por él? → atributo (dimensión).

4. Estructura y criterios del parcial

  • Parte conceptual: preguntas de selección y de explicación breve (definiciones, comparaciones OLTP/OLAP).
  • Parte aplicada: un caso donde diseñas un modelo estrella (identificar hechos, medidas y dimensiones).
CriterioPeso
Dominio conceptual (BI, KPI, OLTP/OLAP)40%
Diseño del modelo estrella40%
Claridad y justificación20%

Cuidado

En la parte aplicada no basta con "dibujar tablas": debes justificar por qué cada campo es medida o atributo y por qué elegiste esas dimensiones.
