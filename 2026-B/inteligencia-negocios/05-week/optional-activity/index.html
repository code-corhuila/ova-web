Preparación para el Parcial del Primer Corte

Llega al parcial con los fundamentos firmes. Autoevalúa tu dominio del Corte 1 y practica el diseño dimensional. Actividad opcional de repaso.

1

Autoevaluar los conceptos del Corte 1.

2

Resolver un caso de modelado estrella.

1. Enunciado

  1. Elabora un resumen de una página con los conceptos del Corte 1: cadena del dato, KPI, OLTP vs OLAP, data warehouse y modelo estrella.
  2. Resuelve este caso: una cadena de farmacias quiere analizar sus ventas por producto, sucursal y mes. Diseña el modelo estrella (hechos, medidas, dimensiones y atributos) y justifícalo.
  3. Marca con honestidad qué temas dominas y cuáles debes repasar antes del parcial.

2. Requisitos

  • Resumen de una página del Corte 1.
  • Modelo estrella del caso de farmacias, justificado.
  • Autodiagnóstico de temas dominados / por repasar.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `05-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 05" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
