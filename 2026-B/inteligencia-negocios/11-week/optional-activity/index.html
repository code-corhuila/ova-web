Crítica visual — lo bueno y lo malo

Aprende a ver como analista: distingue un gráfico que comunica de uno que confunde. Actividad opcional de refuerzo.

1

Evaluar si un gráfico responde su pregunta.

2

Aplicar buenas prácticas de visualización.

1. Enunciado

  1. Busca dos visualizaciones reales: una que consideres buena y una mala (prensa, informes, redes).
  2. Para cada una: ¿qué pregunta responde?, ¿es el gráfico adecuado?, ¿respeta las buenas prácticas (eje en cero, orden, poca tinta, título-conclusión)?
  3. Rediseña la mala: describe o dibuja cómo la mejorarías y por qué.

2. Requisitos

  • Dos gráficos (bueno y malo) con su fuente.
  • Análisis de cada uno según buenas prácticas.
  • Propuesta de rediseño del malo.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `11-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 11" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
