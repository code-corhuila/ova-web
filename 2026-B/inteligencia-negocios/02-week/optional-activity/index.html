Define un KPI para una organización real

Practica la habilidad más transversal del BI: convertir un objetivo de negocio en un indicador medible. Actividad opcional de refuerzo.

1

Formular un KPI atado a una meta.

2

Distinguir dato, información y conocimiento detrás del KPI.

1. Enunciado

Elige una organización que conozcas (tu trabajo, un negocio, la universidad) y trabaja un KPI:

  1. Define el KPI: qué mide, su fórmula y su meta (ej.: tasa de deserción ≤ 5%).
  2. Explica qué decisión habilitaría ese indicador.
  3. Desglosa la cadena: cuál es el dato, la información y el conocimiento detrás del KPI.
  4. Clasifica qué tipo de analítica implica (descriptiva, diagnóstica...).

2. Requisitos

  • Un KPI con fórmula y meta explícita.
  • La decisión que habilita.
  • La cadena dato → información → conocimiento.
  • Tipo de analítica justificado.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `02-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 02" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
