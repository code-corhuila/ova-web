Cierra tu proyecto con el checklist de calidad

El proyecto se pule con criterio. Verifica el ciclo completo y prepara la sustentación. Actividad opcional de refuerzo.

1

Verificar el proyecto con un checklist.

2

Preparar el guion de sustentación.

1. Enunciado

  1. Aplica a tu proyecto el checklist de calidad de la sesión (pregunta, ETL repetible, modelo estrella, medidas, gráficos, interactividad, narrativa, publicación).
  2. Corrige al menos dos puntos que falten o estén débiles y documenta el antes/después.
  3. Prepara el guion de sustentación: pregunta → historia (contexto/nudo/desenlace) → recomendación.

2. Requisitos

  • Checklist aplicado con resultado por ítem.
  • Dos mejoras aplicadas con evidencia.
  • Guion de sustentación estructurado.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `15-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 15" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
