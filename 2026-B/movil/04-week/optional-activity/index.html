Modelo de datos y mockups de tu app

Diseña cómo se guardan los datos y cómo se ven las pantallas de tu app antes de programar. Actividad opcional de refuerzo.

1

Modelar entidades, atributos y relaciones.

2

Diseñar wireframes y el mapa de navegación.

1. Enunciado

  1. Diseña el modelo de datos de tu app: al menos 3 entidades con atributos y sus relaciones (1‑a‑N o N‑a‑N).
  2. Crea wireframes de 3 pantallas clave (baja fidelidad).
  3. Dibuja el mapa de navegación (cómo se pasa de una pantalla a otra).
  4. Indica qué datos irían en local y cuáles en remoto.

2. Requisitos

  • Modelo con 3+ entidades y relaciones.
  • 3 wireframes + mapa de navegación.
  • Decisión local/remoto justificada.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `04-week/` (imágenes o PDF de los wireframes).
  3. Sube los cambios: git add . · git commit -m "Entrega semana 04" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
