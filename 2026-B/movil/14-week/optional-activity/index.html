Optimización y pruebas

Mejora el rendimiento de tu app y añade una base de pruebas. Actividad opcional de refuerzo.

1

Optimizar una pantalla o lista midiendo el impacto.

2

Escribir pruebas unitarias básicas.

1. Enunciado

  1. Elige una pantalla/lista y optimízala (renderizado eficiente, imágenes, evitar llamadas repetidas). Mide antes/después.
  2. Escribe 2 pruebas unitarias de una función (p. ej. cálculo o formateo).
  3. Documenta la mejora y el resultado de las pruebas en el README.

2. Requisitos

  • Optimización con evidencia de mejora.
  • 2 pruebas unitarias que pasan.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `14-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 14" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
