Cierre, despliegue y portafolio

Deja tu proyecto listo para mostrar: preparado para publicar y documentado en tu portafolio. Actividad opcional de refuerzo.

1

Preparar la app para su despliegue.

2

Documentar el proyecto en el portafolio.

1. Enunciado

  1. Genera el build de tu app (ionic build / proyecto nativo) y describe los pasos para publicarla (íconos, permisos, ficha de tienda).
  2. Aplica la retroalimentación final (errores, UX, README).
  3. Redacta la entrada de portafolio: qué hace la app, tecnologías, capturas y qué aprendiste.

2. Requisitos

  • Descripción del proceso de despliegue.
  • Entrada de portafolio completa (README).

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `16-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 16" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
