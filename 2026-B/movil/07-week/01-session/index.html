Lenguajes de programación móviles (Kotlin y TypeScript)

Cada plataforma tiene su lenguaje: Kotlin en Android nativo, Swift en iOS, y TypeScript/JavaScript en el mundo híbrido. Esta sesión da una base de Kotlin (para entender lo nativo) y de TypeScript/React (que usaremos en Ionic).

2. Kotlin en 5 minutos

val nombre = "Ana"      // val: inmutable
var edad = 20           // var: mutable
fun saludar(n: String): String {
    return "Hola, $n"   // interpolación con $
}
class Usuario(val nombre: String, var activo: Boolean) {
    fun describir() = "$nombre (activo=$activo)"
}
val u = Usuario("Luis", true)
println(u.describir())

Nota

Kotlin es conciso (menos código que Java) y moderno: infiere tipos, tiene interpolación de cadenas y clases compactas.

3. Seguridad ante null (Kotlin)

Nota

En Kotlin, un tipo normal no puede ser null; para permitirlo se usa ?. Así el compilador evita muchos NullPointerException.

var texto: String = "hola"   // no admite null
var opcional: String? = null // sí admite null
println(opcional?.length)    // llamada segura: no falla si es null

4. TypeScript/React para Ionic

Como el énfasis del curso es Ionic React, usaremos TypeScript (JavaScript con tipos) y componentes de React. Un componente es una función que devuelve la interfaz:

const Saludo: React.FC = () => {
  const nombre = "Ana";
  return <IonContent>Hola, {nombre}</IonContent>;
};

Tip

Kotlin y TypeScript comparten ideas: tipos, funciones, inmutabilidad (val/const). Entender una te ayuda con la otra.

5. Errores comunes

  • Usar var para todo en Kotlin (prefiere val si no cambia).
  • Ignorar la nulabilidad (?) y provocar errores en ejecución.
  • Confundir = (asignar) con == (comparar).
  • En TS, olvidar los tipos y perder la ayuda del compilador.
