Kotlin básico y un componente Ionic

Practica lo esencial de Kotlin y un componente en Ionic React. Actividad opcional de refuerzo.

1

Escribir una clase Kotlin con validación y null-safety.

2

Crear un componente básico en Ionic React.

1. Enunciado

  1. En Kotlin, crea una clase Producto(nombre, precio) con validación (precio ≥ 0) usando val y manejo de nulos; imprime un par de ejemplos.
  2. En Ionic React, crea un componente Saludo que muestre un nombre y un botón.
  3. Explica en el README dos diferencias entre Kotlin y TypeScript.

2. Requisitos

  • Clase Kotlin con validación y val/nulabilidad.
  • Componente Ionic React funcional.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `07-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 07" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
