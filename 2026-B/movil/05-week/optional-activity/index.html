Dossier de planificación (cierre C1)

Reúne todo lo del Corte 1 en un dossier de planificación de tu app: idea/MVP, backlog, requerimientos, modelo de datos y wireframes. Actividad opcional de refuerzo que deja tu proyecto listo para construir.

1

Integrar la planificación completa del proyecto.

2

Consolidar requerimientos, datos y diseño.

1. Enunciado

Arma un dossier (README + anexos) que reúna, mejorado, lo trabajado en el corte:

  1. Idea, problema, público y MVP (3 funciones).
  2. Backlog priorizado (historias + criterios).
  3. Requerimientos (funcionales y no funcionales) y 1 caso de uso.
  4. Modelo de datos y wireframes con mapa de navegación.

2. Requisitos

  • Un README que enlace/organice las 4 partes.
  • Coherencia entre requerimientos, datos y pantallas.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `05-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 05" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
