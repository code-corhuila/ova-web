Integra cámara o GPS con Capacitor

Usa el hardware del dispositivo desde tu app con un plugin de Capacitor y manejo de permisos. Actividad opcional de refuerzo.

1

Integrar un plugin nativo (cámara o geolocalización).

2

Solicitar y manejar permisos.

1. Enunciado

  1. Integra en tu app un plugin de Capacitor: cámara (tomar y mostrar una foto) o geolocalización (mostrar lat/lng).
  2. Solicita el permiso y maneja el caso en que el usuario lo niega.
  3. Pruébalo en un dispositivo real y documenta con capturas.

2. Requisitos

  • Plugin funcionando con permisos.
  • Manejo del permiso denegado.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `12-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 12" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
