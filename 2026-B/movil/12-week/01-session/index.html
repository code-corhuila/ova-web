Plugins y componentes avanzados (cámara, GPS)

Las apps móviles brillan cuando usan el hardware: cámara, ubicación, almacenamiento. Con Capacitor, Ionic accede a estas capacidades nativas mediante plugins. Esta sesión enseña a integrar cámara y GPS, y a manejar permisos correctamente.

1. Capacitor y los plugins

Nota

Capacitor es el puente de Ionic hacia el hardware. Un plugin expone una función nativa (cámara, GPS, archivos) con una API de JavaScript, para usarla igual en Android e iOS.

Tu código (JS/TS) → Plugin de Capacitor → API nativa (Android/iOS) → Hardware

2. Cámara

import { Camera, CameraResultType } from "@capacitor/camera";

async function tomarFoto() {
  const foto = await Camera.getPhoto({
    quality: 80,
    resultType: CameraResultType.Uri,
  });
  return foto.webPath; // ruta para mostrar la imagen
}

3. Geolocalización (GPS)

import { Geolocation } from "@capacitor/geolocation";

async function ubicacion() {
  const pos = await Geolocation.getCurrentPosition();
  return { lat: pos.coords.latitude, lng: pos.coords.longitude };
}

4. Permisos

Cuidado

Cámara, ubicación y otros recursos requieren permiso del usuario. Hay que declararlos en la configuración de la plataforma y solicitarlos en tiempo de ejecución; si el usuario los niega, la app debe seguir funcionando con una alternativa o un mensaje claro.

5. Almacenamiento en el dispositivo

Para guardar datos localmente (preferencias, caché) se usan plugins como Preferences (clave‑valor) o una base local (SQLite). Útil para funcionar offline y recordar la sesión.

6. Errores comunes

  • No declarar/solicitar permisos → la función falla en el dispositivo.
  • Asumir que el permiso siempre se concede (manejar la negativa).
  • Probar cámara/GPS solo en el navegador (requiere dispositivo real).
  • Guardar datos sensibles sin cifrar.
