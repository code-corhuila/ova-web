Proyecto final — app móvil completa

Todo converge aquí: construyes una app móvil funcional de principio a fin, integrando planificación, diseño, frontend, backend, uso de hardware y calidad. Esta sesión define el alcance, los requisitos y los criterios con que se evalúa el proyecto.

1

Definir el alcance y requisitos del proyecto final.

2

Integrar frontend, backend y hardware.

3

Documentar y preparar la entrega/sustentación.

1. Objetivo

Desarrollar una aplicación móvil funcional que resuelva un problema real, integrando lo aprendido en el semestre. El énfasis del curso es Ionic React, pero el proyecto puede entregarse en la tecnología que elijas (Ionic, React Native, Android/Kotlin), justificando la decisión.

2. Requisitos mínimos (checklist)

  • Planificación: problema, MVP, backlog (viene de C1).
  • Diseño: modelo de datos + pantallas (mockups/navegación).
  • Frontend: varias pantallas con navegación y estado.
  • Backend + conectividad: consumo de una API (o servicios) con manejo de errores.
  • Hardware: al menos un plugin nativo (cámara, GPS u otro) o almacenamiento local.
  • Calidad: manejo de estados (carga/error), y alguna prueba.
  • README con descripción, tecnologías, instrucciones y capturas.

3. Arquitectura sugerida

App (pantallas + estado)
   ↓  servicio (fetch, token, errores)
API/Backend  ↔  Datos (local + remoto)
   ↑  plugins (cámara / GPS / almacenamiento)

Tip

Empieza por el MVP: que funcione el flujo principal de punta a punta antes de agregar extras. Un proyecto pequeño y terminado vale más que uno grande a medias.
