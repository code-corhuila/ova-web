Herramientas de desarrollo móvil

Empieza la construcción. Antes de programar hay que montar el entorno: SDKs, IDE, emuladores y el gestor de paquetes. Esta sesión prepara tu máquina para desarrollar apps nativas (Android Studio) e híbridas (Node + Ionic), el entorno que usaremos el resto del curso.

1

Reconocer los entornos Android Studio y Xcode.

2

Instalar Node.js y el CLI de Ionic.

3

Usar emuladores/dispositivos para probar.

4

Entender el rol del SDK y el gestor de paquetes.

1. Los entornos de desarrollo (IDE + SDK)

Nota

Un SDK (Software Development Kit) trae las librerías y herramientas para construir apps de una plataforma. El IDE es el editor que integra todo (código, emulador, depurador).

PlataformaIDESDK / lenguaje
Android (nativo)Android StudioAndroid SDK · Kotlin/Java
iOS (nativo)Xcode (solo macOS)iOS SDK · Swift
HíbridoVS Code + Node.jsIonic / React Native (JS/TS)

2. Emuladores y dispositivos

Para probar sin un teléfono físico se usan emuladores (Android Virtual Device en Android Studio, Simulator en Xcode). También puedes conectar un dispositivo real por USB con la depuración activada.

Tip

El emulador es cómodo para desarrollar; siempre prueba en un dispositivo real antes de entregar: el rendimiento y los gestos se sienten distinto.

3. Node.js y el CLI de Ionic

Para el desarrollo híbrido (nuestro énfasis, Ionic React) necesitas Node.js (trae npm, el gestor de paquetes) y el CLI de Ionic:

1. Instala Node.js LTS (incluye npm)
2. Instala el CLI:      npm install -g @ionic/cli
3. Crea un proyecto:    ionic start miApp blank --type=react
4. Ejecútalo:           ionic serve

Nota

npm descarga las dependencias (librerías) que declara tu proyecto en package.json. ionic serve levanta la app en el navegador con recarga automática.

4. Estructura básica de un proyecto Ionic React

miApp/
  src/
    pages/       -> pantallas (componentes React)
    components/  -> componentes reutilizables
    App.tsx      -> raíz y rutas
  package.json   -> dependencias y scripts
  ionic.config.json

5. Errores comunes

  • No instalar la versión LTS de Node (incompatibilidades).
  • Olvidar npm install tras clonar un proyecto (faltan dependencias).
  • Probar solo en emulador y nunca en dispositivo real.
  • Confundir el IDE (editor) con el SDK (herramientas de la plataforma).
