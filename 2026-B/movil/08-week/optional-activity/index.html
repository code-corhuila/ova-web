API REST con Express y consumo desde la app

Construye un backend mínimo con Express y consúmelo desde una función fetch. Actividad opcional de refuerzo.

1

Crear endpoints GET y POST con Express.

2

Consumir la API en JSON desde la app.

1. Enunciado

  1. Crea una API REST con Express para una entidad (p. ej. tareas): GET /tareas y POST /tareas.
  2. Prueba los endpoints (Postman, Thunder Client o el navegador).
  3. Escribe una función fetch que liste las tareas y otra que cree una, manejando errores.

2. Requisitos

  • Endpoints GET y POST funcionando (JSON).
  • Funciones fetch con manejo de error.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `08-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 08" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
