Backend básico para aplicaciones móviles

Las apps rara vez viven solas: consultan y guardan datos en un servidor. Esta sesión introduce un backend sencillo con Node.js y Express que expone una API REST, y cómo la app móvil la consume con peticiones HTTP en formato JSON.

1. ¿Qué es una API REST?

Nota

Una API REST expone recursos (usuarios, productos…) mediante URLs y métodos HTTP. La app cliente pide datos al servidor y este responde, normalmente en JSON.

MétodoAcción (CRUD)Ejemplo
GETLeerGET /productos
POSTCrearPOST /productos
PUTActualizarPUT /productos/5
DELETEEliminarDELETE /productos/5

2. Un backend mínimo con Express

const express = require("express");
const app = express();
app.use(express.json());

let productos = [{ id: 1, nombre: "Café" }];

app.get("/productos", (req, res) => res.json(productos));
app.post("/productos", (req, res) => {
  const nuevo = { id: productos.length + 1, nombre: req.body.nombre };
  productos.push(nuevo);
  res.status(201).json(nuevo);
});

app.listen(3000, () => console.log("API en http://localhost:3000"));

Nota

express.json() permite leer el cuerpo JSON de las peticiones. res.json(...) responde en JSON. El código 201 significa "creado".

3. JSON: el idioma entre app y servidor

Nota

JSON (JavaScript Object Notation) es un formato de texto para intercambiar datos: pares clave‑valor, listas y objetos anidados.

{ "id": 1, "nombre": "Café", "precio": 3500 }

4. Consumir la API desde la app (Ionic React)

async function cargarProductos() {
  const resp = await fetch("http://localhost:3000/productos");
  const datos = await resp.json();
  return datos; // lista de productos
}

Tip

En producción, la URL no es localhost sino la del servidor desplegado; y las peticiones deben manejar errores (try/catch) y estados de carga.

5. Errores comunes

  • Olvidar express.json() y no poder leer req.body.
  • No manejar errores de red en la app (la petición puede fallar).
  • Mezclar responsabilidades: la app NO debe tener la lógica del servidor.
  • Exponer datos sensibles sin autenticación.
