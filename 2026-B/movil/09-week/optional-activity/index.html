Pantalla con lista y navegación en Ionic React

Construye una pantalla real con componentes de Ionic React, estado y navegación. Actividad opcional de refuerzo.

1

Usar componentes de Ionic React (IonList, IonButton).

2

Manejar estado con useState y navegar entre páginas.

1. Enunciado

  1. Crea una pantalla con una lista (IonList) de al menos 5 elementos.
  2. Añade un contador o un campo que use useState.
  3. Agrega una segunda página y navega a ella (React Router).
  4. (Ideal) Carga la lista desde tu API de la semana 8 con fetch.

2. Requisitos

  • Lista con componentes de Ionic React.
  • Estado con useState + navegación a 2ª página.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `09-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 09" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
