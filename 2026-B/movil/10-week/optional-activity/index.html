Mini-app integradora (cierre C2)

Integra lo del Corte 2 en una mini-app Ionic React conectada a tu backend. Actividad opcional de refuerzo que adelanta tu proyecto.

1

Integrar frontend Ionic React con backend Express.

2

Consolidar componentes, estado y navegación.

1. Enunciado

Construye una mini-app que integre lo visto:

  1. Backend Express con una entidad (GET + POST).
  2. Ionic React: pantalla que lista los datos (fetch) y un formulario que crea uno nuevo.
  3. Navegación a una pantalla de detalle.
  4. Manejo básico de errores de red.

2. Requisitos

  • Frontend + backend funcionando juntos.
  • Listar y crear datos desde la app.

3. Cómo entregar (por GitHub)

Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana. Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.

  1. Haz fork del repositorio de la clase y clónalo.
  2. Coloca tu entrega en la carpeta `10-week/`.
  3. Sube los cambios: git add . · git commit -m "Entrega semana 10" · git push.
  4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
